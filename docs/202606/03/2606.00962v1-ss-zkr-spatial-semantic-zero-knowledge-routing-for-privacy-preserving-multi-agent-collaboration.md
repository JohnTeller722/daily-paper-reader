## 摘要
基础智能体互操作性标准（特别是智能体间（A2A）协议和模型上下文协议（MCP））推动了多智能体系统的通信，而利用W3C去中心化标识符（DID）和可验证凭证（VC）的补充身份框架提供了密码学智能体认证。然而，现有协议均不支持在无需路由中介解密载荷的情况下，跨组织信任边界进行基于内容的语义路由，而这正是受GDPR、HIPAA和MiFID II等合规敏感环境中的硬约束。我们提出SS-ZKR，一种三机制隐私保护路由协议，设计为A2A/MCP的补充层。机制一通过差分隐私语义意图向量引入盲路由，该向量密码学绑定到载荷模式一致性的零知识证明。机制二提供向量加权自适应载荷净化，对数值字段采用形式化(ε,δ)-差分隐私，对文本字段采用启发式语义聚合。机制三提出空间到密码学策略编译器，将视觉定义的信任区拓扑转化为确定性零知识访问电路。我们提供了形式化威胁模型，分析了意图向量的信息泄露界限，给出了所有三种机制的伪代码，以及与基于TEE和同态加密的路由基线的分析复杂度比较。SS-ZKR使金融服务、医疗保健和国防领域的企业能够跨监管边界编排异构AI智能体，而无需将专有数据暴露给路由基础设施。

## Abstract
Foundational agent interoperability standards, notably the Agent-to-Agent (A2A) protocol and the Model Context Protocol (MCP), have advanced multi-agent system communication, and complementary identity frameworks leveraging W3C Decentralised Identifiers (DIDs) and Verifiable Credentials (VCs) provide cryptographic agent authentication. However, no existing protocol supports content-based semantic routing of agent payloads across organisational trust boundaries without requiring the routing intermediary to decrypt the payload, which is a hard constraint in compliance-sensitive environments governed by GDPR, HIPAA, and MiFID II. We propose SS-ZKR, a three-mechanism privacy-preserving routing protocol designed as a complementary layer atop A2A/MCP. Mechanism I introduces blind routing via differentially private semantic intent vectors cryptographically bound to zero-knowledge proofs of payload-schema consistency. Mechanism II offers vector-weighted adaptive payload sanitisation with formal (epsilon, delta)-differential privacy for numerical fields and heuristic semantic aggregation for textual fields. Mechanism III presents a spatial-to-cryptographic policy compiler that translates visually defined trust-zone topologies into deterministic zero-knowledge access circuits. We provide a formal threat model, analyse information leakage bounds of intent vectors, present pseudocode for all three mechanisms, and give analytical complexity comparisons against TEE-based and homomorphic encryption-based routing baselines. SS-ZKR lets enterprises in financial services, healthcare, and defence orchestrate heterogeneous AI agents across regulatory boundaries without exposing proprietary data to routing infrastructure.

**核心问题**：当前多智能体系统（MAS）通信协议（如Google的A2A协议、Anthropic的MCP协议）虽然在智能体发现、任务管理和工具集成方面取得进展，但所有协议都要求路由中间节点（如Agentic Mesh Fabric）能够访问负载（payload）的明文内容才能做出路由决策。这在受GDPR、HIPAA、MiFID II等数据主权法规约束的企业环境中是不可接受的——任何中间基础设施（包括内部路由中间件）不得访问智能体间负载的明文内容，除非对每个数据类都有明确授权。这一合规性僵局已在金融服务、医疗保健和国防领域严重阻碍了MAS的采用。

**研究动机**：需要一种协议，在不要求路由中介解密负载的前提下，实现基于内容的语义路由（content-based semantic routing）。现有技术如可搜索对称加密（SSE）仅支持精确匹配，功能加密（FE）计算开销过高，私密信息检索（PIR）扩展性差，安全多方计算（SMPC）不适用于无状态路由。此外，Morris等人证明了文本嵌入几乎与原始文本一样可被重构，任何基于嵌入的路由方案都必须考虑信息泄露风险。

### 核心思想
SS-ZKR由三种相互依赖的机制组成，共同实现隐私保护路由：

### 机制I：差分隐私盲路由（Differentially Private Blind Routing）
- **步骤1 - 意图嵌入**：源智能体通过共享嵌入模型 f_embed 生成d维语义意图向量 v_i。
- **步骤2 - 差分隐私扰动**：添加高斯噪声并重归一化：ṽ_i = (v_i + η) / ||v_i + η||，其中 η ~ N(0, σ²I_d)，σ 根据(ε,δ)-差分隐私高斯机制校准。重归一化后仍保持DP保证。
- **步骤3 - 零知识模式证明与噪声绑定**：源智能体构建zk-SNARK证明π_i，证明存在(v_i, η, payload)使得：ṽ_i通过噪声绑定与v_i关联；payload符合v_i对应的模式类C(v_i)；ciphertext正确加密payload。这确保AMF验证π_i后知道用于路由的ṽ_i与声明意图一致。
- **步骤4 - 盲路由执行**：AMF接收(ṽ_i, π_i, ciphertext)，验证π_i，计算ṽ_i与能力注册表中各能力向量v_c的余弦相似度，选择相似度高于阈值θ的最高者路由。

### 机制II：向量加权自适应载荷净化（Vector-Weighted Adaptive Sanitisation）
- 定义**语义信任距离**：D(S,D) = 1 - sim(v_auth, v_sec)，其中v_auth来自请求者的VC属性嵌入，v_sec来自目的智能体的安全分类向量。
- **净化函数**：Φ(r, D) = M_ε(Agg(r, D))。Agg是语义聚合函数，根据D降低特异性（数值→范围，实体→角色，时间戳→时间段）；M_ε是(ε,δ)-DP机制。
- **混合净化**：数值字段使用高斯机制提供形式化(ε,δ)-DP保证；文本字段采用启发式语义聚合（降级特异性），不声称形式化DP保证。

### 机制III：空间到密码学策略编译器（Spatial-to-Cryptographic Policy Compiler）
- 将视觉定义的信任区拓扑（画布上的区域、嵌套、重叠）通过三步编译为确定性ZK访问电路：
  1. **拓扑解析**：将画布离散为平面细分，用计算几何提取区域包含和相交关系，得到区域邻接图G_Z。
  2. **信任系数推导**：根据区域嵌套深度和管理员覆盖设定κ(Z_i, Z_j)；非相邻区域取最短路径上κ的最小值。
  3. **电路合成**：每个区域边界编译为算术电路，编码所需的VC属性证明连接，复杂度O(a·k)（a为属性数，k为VC链最大深度）。
- 输出：每个区域对的(ZK电路C_{i,j}, 净化阈值τ_{i,j}, 隐私参数ε_{i,j})。
