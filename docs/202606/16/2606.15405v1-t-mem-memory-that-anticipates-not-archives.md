## 摘要
长期记忆对于对话代理在长时间对话中保持连贯、履行多个会话前作出的承诺以及调整其行为以适应每个用户至关重要。然而，当前基于大语言模型的长期对话记忆在可到达性上受限于查询与存储内容（包括词汇和稠密向量）之间的相似性。当查询和记忆共享表面特征（如措辞或命名实体，我们称之为描述性）时，这种方法有效。但它忽略了另一类同样有价值的情况，即查询和记忆不共享表面特征，仅通过潜在语义弧（联想性）联系在一起。在这种模式下，现有的长期记忆系统普遍失败。覆盖这另一半使得助手能够首次主动将过去的对话作为语义资产加以利用。在记忆方面，这是认知科学中所谓情景未来思维的工程对应物：预演过去的经验，以便在未来需要找到它的上下文中使用。我们将这些写入时的预演称为触发器。我们提出T-Mem，这是首个同时覆盖描述性和联想性回忆的长期对话记忆架构。在两种证据粒度（单个事实和完整对话）上，T-Mem分别实例化一个描述性触发器家族和一个联想性触发器家族，使得每个记忆都能通过表面相似和相关性限制的查询到达。作为实证验证，T-Mem在LoCoMo和LoCoMo-Plus上均达到了最先进水平。

## Abstract
Long-term memory is essential for conversational agents to remain coherent across extended dialogues, follow through on commitments made many sessions earlier, and adapt their behaviour to each user. Current LLM-backed long-term conversational memory, however, is reachability-bounded by the similarity between a query and stored content, both lexical and dense-vector. The approach is effective when query and memory share surface features such as wording or named entities (we call this descriptive). But it misses another, equally valuable class of cases, where query and memory do not share surface features and are tied only by a latent semantic arc (associative). On this regime prevailing long-term memory systems collectively fail. Covering this other half is what allows an assistant, for the first time, to actively draw on past dialogue as a semantic asset. On the memory side, this is the engineering counterpart of what cognitive science calls episodic future thinking: rehearsing past experience for the future contexts under which it will need to be found. We call these write-time rehearsals triggers. We propose T-Mem, the first long-term conversational memory architecture that covers both descriptive and associative recall. At each of two evidence granularities, single facts and full exchanges, T-Mem instantiates one descriptive trigger family and one associative trigger family, so that every memory remains reachable from both surface-similar and relevance-bound queries. As empirical validation, T-Mem reaches state-of-the-art on both LoCoMo and LoCoMo-Plus.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有长期对话记忆系统（如Flat RAG、图结构记忆、代理层级记忆、OS风格记忆内核）都采用单一的相似性检索范式——将查询与存储内容通过词法BM25或密集向量投影到同一空间，取top-K。这种机制仅能处理**描述性回忆**（查询与记忆共享表面特征如措辞、命名实体），而无法处理**联想性回忆**（查询与记忆之间无表面词汇重叠，仅通过因果链、叙事延续等潜在语义弧关联）。
- **背景**：用户在长期对话中很少用完全相同措辞重提旧话题，往往通过间接线索（新情境触发）回溯。相似性检索只能沿着词汇或语义距离收敛，当目标的表面形式已经漂移时，同一邻域内永远无法到达目标。这导致现有系统存在结构性盲区。
- **整体意义**：覆盖联想性回忆是让对话代理首次能够主动将过去对话作为语义资产加以利用，相当于认知科学中“情景未来思维”的工程实现——在写入时预演记忆在未来需要被找到的上下文。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：提出T-Mem架构，通过**写时排练（write-time rehearsal）**生成触发器（triggers），将“如何到达记忆”与“什么是证据”解耦。在两种证据粒度（单个事实item和完整对话scene）上，每个粒度都实例化一个描述性触发器家族和一个联想性触发器家族，覆盖2×2检索空间（粒度×取向）的全部四个象限：
  - **Entity Trigger（Q I）**：用上位概念命名item，支持描述性item级回忆。
  - **Bridge Trigger（Q II）**：将item投射到需要知道该item的场景（例如，“过敏”投射到“选择团队晚餐餐厅”），支持联想性item级回忆。
  - **Scene Trigger（Q IV）**：沿情境、物体、事件、情感四个属性描述当前scene，支持描述性scene级回忆。
  - **Horizon Trigger（Q III）**：将scene投射到前瞻性维度，支持联想性scene级回忆。
- **关键技术细节**：
  - **记忆结构**：包含场景（VS）、原子事实（VI）、主题标签（VT）、四族触发器（T^Ent、T^Brg、T^Scn、T^Hor）、人物画像（X）。触发器和证据分离；主题标签仅用于预过滤，不进入QA通道；人物画像作为环境上下文注入。
  - **构建流程**：四阶段流水线——场景分割（事件边界检测）、主题分配（批处理匹配/新建/更新）、item提取（原子item和连接item）、触发器实例化（每个item生成Entity+Bridge，每个scene生成Scene+Horizon）。
  - **索引**：节点索引（BM25+per-type密集表）；触发器感知索引（每个item通过概念视图、桥接视图、联合视图三个视角编码，取余弦相似度最大值作为宿主item得分）。
  - **检索级联**：顶级→主题预过滤（k_T=15）→场景选择（k_S=5，结合相似性和场景触发器/水平触发器）→item选择（k_I=15，场景绑定item结合Entity/Bridge触发器，硬余弦门限0.85）。使用倒数秩融合（RRF）融合词法和密集排名。
- **公式**：RRF(d)=∑_{m=1}^M 1/(k_0+rank_m(d))，其中M为融合排名列表数，k_0为平滑常数（设为60）。
