## 摘要
大语言模型（LLMs）越来越需要与用户进行长时间跨度的交互。然而，由于其有限的上下文窗口，LLMs 无法保留所有过去的交互，因此长期记忆管理对于存储、更新和检索超出上下文限制的历史信息至关重要。尽管最近的记忆系统试图通过外部存储历史信息来解决这一问题，但现有方法存在三个关键局限：基于平面的文本记忆组织无法捕捉记忆之间的显式关系；结构化记忆系统通常会破坏性地覆盖演变的事实；当前的检索机制在证据不完整时仍然是与查询无关且被动的。REAL 将长期对话记忆构建为一种时间感知和置信度感知的有向属性图，其中每个原子事实都用实体、关系、有效时间区间、置信度分数和探索意图标签表示。在记忆构建过程中，REAL 采用非破坏性的时间更新策略，保留并行的事实版本及其有效区间，从而实现对事实演变的忠实追踪。在检索过程中，REAL 锚定与查询相关的根实体，解耦其探索意图，并执行语义评估器引导的混合波束搜索，以提取紧凑的记忆子图。它还进一步引入反事实推理来修复不可靠的检索状态，并通过隐式逻辑关系恢复缺失的记忆证据。综合实验表明，REAL 在平面文本、基于图和现有记忆基线之上显著提升了长期记忆性能，平均提升 22.72%。

## Abstract
Large Language Models (LLMs) are increasingly expected to interact with users over long time horizons. However, due to their finite context window, LLMs cannot retain all past interactions, making long-term memory management essential for storing, updating, and retrieving historical information beyond the context limit. Although recent memory systems attempt to address this issue by storing historical information externally, existing approaches suffer from three key limitations: flat text-based memory organizations fail to capture explicit relations among memories, structured memory systems often destructively overwrite evolving facts, and current retrieval mechanisms remain query-agnostic and passive when evidence is incomplete. REAL constructs long-term conversational memory as a temporal and confidence-aware directed property graph, where each atomic fact is represented with entities, relations, valid-time intervals, confidence scores, and exploration intent labels. During memory construction, REAL adopts a non-destructive temporal update strategy that preserves parallel fact versions and their validity intervals, enabling faithful tracking of fact evolution. During retrieval, REAL anchors query-relevant root entities, decouples their exploration intents, and performs semantic evaluator-guided hybrid beam search to extract compact memory subgraphs. It further incorporates counterfactual inference to repair unreliable retrieval states and recover missing memory evidence through implicit logical relations. Comprehensive experiments demonstrate that REAL substantially improves long-term memory performance over flat-text, graph-based, and existing memory baselines, achieving an average improvement of 22.72\%.

## 1. 核心问题与整体含义

随着大语言模型（LLMs）在长期多轮对话、个人AI助手等场景中广泛应用，LLM需要跨会话、跨天甚至跨月的长期记忆能力。然而，LLM的上下文窗口是有限的（通常8K~256K tokens），无法无限累积历史信息。即使将全部历史放入上下文，注意力机制也会随距离衰减，且主题跳跃时关键事实容易淹没在无关内容中。因此，必须设计外部记忆管理系统来存储、更新和检索超出上下文限制的历史信息。

现有记忆系统存在三大缺陷：
- **C1：扁平文本组织**——文本块之间缺乏显式链接，无法进行多跳检索和路径推理。
- **C2：缺乏事实演化**——结构化记忆采用破坏性覆盖，抹去了事实随时间演变的轨迹（如用户喜好从“意大利菜”变为“日本菜”被直接替换）。
- **C3：检索低效且被动**——检索策略与查询意图无关，且当证据不足时只能回答“不知道”，无法利用隐含逻辑关系进行反事实推理。

论文提出REAL框架，旨在通过推理增强的图结构有效管理LLM长期记忆，同时解决上述三个挑战。

## 2. 方法论

### 核心思想
REAL将长期对话记忆构建为**时序与置信度感知的有向属性图**，在记忆构建阶段采用**非破坏性时间更新**保留事实演进，在检索阶段通过**语义评估器引导的混合波束搜索**和**反事实推理**实现查询感知、主动的证据发现。

### 关键技术细节

#### 记忆构建
- 将会话流转换为原子事实六元组：`(h, r, t, [τs, τe], c, ι)`，其中`h`头实体，`r`关系，`t`尾实体，`[τs,τe]`有效时间区间，`c`置信度（0~1），`ι`探索意图标签（FACT/CAUSAL/TEMPORAL/CONTRAST/EVOLUTION）。
- **非破坏性时间更新**：对于单值关系（如“当前居住城市”），若新事实与旧事实的尾实体不同且时间区间重叠，则关闭旧事实的结束时间（设τe为新事实开始时间），插入新事实，保留并行版本。对于多值关系（如“喜欢食物”），直接添加新边。这保证了事实演化的完整历史不被覆盖。
- **置信度分层**：初始由LLM根据语言线索（如“可能”为低置信度，“总是”为高置信度）赋值。检索时仅使用置信度≥θstable（默认0.8）的边作为核心证据，后续对话可以升级置信度。
- **探索意图标记**：在提取事实时标注其支持推理的类型（因果、时序、对比、演化等），用于后续检索时对齐查询意图。

#### 记忆检索
- **根实体锚定与意图解耦**：从查询中提取根实体，并推断每个实体的探索意图（如查询“为什么用户喜欢日本菜？”，则“用户”实体的意图为CAUSAL）。
- **语义评估器引导的混合波束搜索**（算法1）：从每个根实体开始，维护k个波束路径。每一步：
    1. **候选节点扩展**：对当前路径末端实体，获取其直接邻居。通过三重过滤（时间有效性、置信度阈值、意图兼容性）得到原始候选集，再根据语义相似度选取top‑m个候选。
    2. **路径评分**：语义评估器对当前路径和所有候选扩展路径打分，分数由三部分组成：**查询相关性（SQR）**、**逻辑连贯性（SLC）**、**实体特定回答充分性（SAS）**。
    3. **决策**：比较当前路径与扩展路径的SAS分数。若当前路径足够高则**停止**（加入最终证据池）；若有更高分扩展则**扩展**；若扩展不可靠（无有效邻居或相似度/连贯性低于阈值δQR/δLC）则触发**反事实推理**。
    4. **反事实推理**：利用预先定义的规则（对称性、上下位关系、时序后继、因果关系、共现关系）生成替代遍历假设，恢复缺失证据。每个波束有预算上限`B_cf`，只保留评分最高的top‑B_cf条路径。
    5. **全局波束剪枝**：合并所有候选路径，保留top‑k继续下一轮。
- 检索得到的子图序列化为紧凑证据上下文，包含路径、时间戳、置信度，送入LLM生成最终答案。

## 6. 主要结论与发现

- REAL在所有6个数据集和3种骨干模型上**一致优于**所有基线，平均LLM-as-Judge得分提升22.72%。
- 相比Full Context提升49.33%，相比扁平文本方法提升23.85%，相比图记忆基线提升12.71%，说明结构化、时序、推理增强的记忆管理的重要性。
- 消融实验显示每个组件均有贡献：**语义评估器影响最大**（去除后下降4.44%），其次为反事实推理（下降2.22%）、探索意图（下降2.05%）。

## 7. 优点

- **方法创新性强**：将记忆管理建模为数据管理问题，首次同时引入时序、置信度、探索意图、反事实推理等多个维度，形成完整框架。
- **实验设计严谨**：覆盖6个代表性基准、3种骨干模型、多种基线，消融和超参数分析全面，还提供了效率分析和案例研究。
- **可解释性较好**：图结构显式记录事实演化和推理路径，检索过程中的停止/扩展/反事实决策都有明确定义。
- **性能提升显著**：在所有实验设置下均稳定超越SOTA，证明了方法的通用性和有效性。

## 8. 不足与局限

- **依赖LLM的质量**：事实提取、置信度赋值、探索意图标注均依赖LLM，可能引入噪声或遗漏。论文未讨论对LLM自身能力的敏感性。
- **超参数较多**：波束宽、深度、候选数、置信度阈值、反事实阈值等均需手动调整，不同场景可能需要重新调优。虽然提供了默认值，但通用性受限。
- **检索开销**：尽管效率分析显示延迟可控，但构建和检索延迟仍高于部分基线（如Flat Memory Chunk）。在实时性要求极高的场景下可能不够理想。
- **反事实推理规则**：目前仅包含对称、上下位、时序、因果、共现五类规则，覆盖范围有限；规则的正确性依赖手动定义，无法自动学习。
- **未验证跨模态或超长对话扩展性**：数据集最长约300轮/9K tokens，未测试更大规模（如数千轮）下的性能退化和内存占用。
- **对“未知”场景的处理**：论文未讨论当检索到的记忆完全不足以回答查询时，REAL是否会滥用反事实推理生成不准确答案。反事实推理有可能引入幻觉，文中缺乏对此的量化分析。
