## 摘要
LLM代理的长期记忆不仅仅是适时检索正确的段落。当前的记忆系统将信念修订、因果耦合和跨领域抽象压缩到单一的检索表面，该表面针对表面回忆进行优化，因此在需要推理用户如何演变的隐式个性化方面表现不佳。我们提出DCPM，它沿着认知能力层级重新组织代理记忆，从原始输入和原子事实，经过历时信念轨迹和身份，再到领域模式、潜在意图和跨领域模式。该层级由继承双过程理论架构划分的两个过程驱动：同步的白天写入器（系统1），记录信念修订为双向链接的取代链；以及异步的夜间引擎（系统2），归纳模式和意图，并扫描跨领域冲突，将其抽象为更高级的核心模式。在LongMemEval、PersonaMem和PersonaMem-v2上，启用系统2在基准奖励隐式跨会话推理时贡献最大（在PersonaMem-v2上最高+5.20），在跨度回忆时贡献最小，这与架构预测一致。

## Abstract
Long-term memory for an LLM agent is more than retrieving the right passage at the right time. Current memory systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall, and consequently struggle on implicit personalisation that requires reasoning over how a user has evolved. We propose DCPM, which reorganises agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and identity, to domain schemas, latent intentions and cross-domain patterns. The hierarchy is driven by two processes inheriting the architectural split of dual-process theory: a synchronous daytime writer (System1) that records belief revisions as doubly linked supersedes chains, and an asynchronous nighttime engine (System2) that induces schemas and intentions and sweeps for cross-domain collisions abstracted into higher-level core schemas. On LongMemEval, PersonaMem and PersonaMem-v2, enabling System2 contributes most where the benchmark rewards implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall, matching the architectural prediction.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的 LLM 代理长期记忆系统通常将记忆视为单纯的存储与检索问题（如向量存储、时序知识图谱），将信念修订、因果耦合与跨领域抽象全部压缩到单一的检索平面上，导致代理无法回答需要**隐式个性化推理**的问题——例如理解用户偏好的演变原因、跨生活领域的潜在关联等。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **认知能力层级**：将代理记忆按认知复杂度从低到高组织为五层：
  1. **原始输入**（raw inputs）与**原子事实**（atomic facts）
  2. **身份条目**（identity items）与**历时信念轨迹**（diachronic supersedes chains）
  3. **领域内行为模式**（schemas）
  4. **潜在意图**（intentions）
  5. **跨领域核心模式**（cross-domain core schemas）
- **双过程架构**：继承心理学“双过程理论”的架构划分，而非功能细节：
  - **系统1（System 1）**：同步白天写入器，每次 `add_memory` 请求时执行，在数秒内记录信念修订，生成**双向链接的取代链**（supersedes chains）。
  - **系统2（System 2）**：异步夜间引擎，在空闲时段运行（允许数十秒），从事买的事实中**归纳**出模式、意图，并通过**双空间碰撞扫描**提取跨领域核心模式。

### 2.2 关键技术细节

- **系统1写入流程**（Algorithm 1）：
  1. 原始持久化：将用户输入写入向量库（零损失保证）。
  2. 提取：调用提取 LLM（`M_e`）从当前轮次结合近期历史窗口提取事实与身份条目，附上类型、主题、显著性、时间戳。
  3. 调和：调和 LLM（`M_r`）对比提取项与向量库中 top-k 近邻，做出 **ADD / SUPERSEDE / UPDATE** 决策（重复项忽略）。
  4. 批量写回：将保留项批量嵌入并写入向量库；对 SUPERSEDE 项添加双向指针（`new.SUPERSEDES = old`，`old.SUPERSEDED_BY = new`），形成双向链表，旧条目不删除。

- **系统2异步引擎**（Algorithm 2）：
  - **Phase 1（无 LLM 预处理）**：筛选未被纳入任何模式或意图节点的“新鲜事实”，使用两阶段 DBSCAN 聚类，计算质心嵌入，检索附近已有图节点。
  - **Phase 2（LLM 归纳智能体）**：对每个聚类，调用 `M_a`（配备四个工具：创建模式、创建意图、添加证据边、添加结构边），增量更新图 G。
  - **Phase 3（跨领域扫描器）**：
    - 对每个模式节点，用 LLM 生成简短行为描述，分别编码为行为空间嵌入 `E_beh` 和语义空间嵌入 `E_sem`。
    - **碰撞条件**：`cos(E_beh(si), E_beh(sj)) > θ_beh` 且 `cos(E_sem(si), E_sem(sj)) < θ_sem`（即行为相似但语义不同）。
    - 对碰撞簇，调用另一 LLM 归纳核心模式，写回图。

- **读路径**：查询时仅依赖向量搜索 + 指针遍历 + 图查找，**全程不调用 LLM**，延迟受向量查询主导。
- **复杂度**：
  - 写入：系统1为 O(N log N)（HNSW 索引）加两次 LLM 调用。
  - 系统2：Phase 1 无 LLM，O(N)；Phase 2 每聚类一次 LLM 调用；Phase 3 每模式一次抽象 LLM 调用 + O((D·s̄)²) 向量比较 + 每碰撞簇一次核心归纳 LLM。
  - 读取：O(log N + k̄·)，k̄ 为取代链平均长度（≤4）。

## 6. 论文的主要结论与发现

1. **双过程分拆是有效的**：系统2仅在需要隐式跨会话推理的任务（PersonaMem-v2）上带来显著增益（+2.51 ~ +5.20），在事实回溯类任务上增益微小，与理论预测一致。
2. **取代链机制弥合历时连续性**：在 LongMemEval 知识更新子集上，78% 的正确回答使用了取代指针（不正确时仅 31%），证明取代链对恢复演化后信念状态至关重要。
3. **跨领域核心模式贡献最大**：消融实验表明，双空间碰撞机制贡献约 4.1 个点（占系统2总增益的 80%），而模式/意图层贡献约 1.1 个点。
4. **DCPM 在 PersonaMem-v2 上超越长上下文代理**（kimi-2.5 下 59.30 vs 58.46），表明结构化记忆可缓解“中间信息丢失”问题。
5. **读路径无 LLM 调用**，延迟仅由向量搜索主导，具备部署可行性。

## 7. 优点

- **理论驱动**：从认知科学（双过程理论、心理理论、重建记忆）中汲取灵感，设计了有理论依据的层级和双过程分拆，而非启发式工程堆叠。

  - 取代链明确保留信念轨迹，不同于常见的 in-place update。
  - 双空间碰撞扫描（行为相似 vs 语义不同）设计新颖，能提取人类难以直接发现的跨域关联。
  - 读路径纯检索，无 LLM 调用，效率高。
- **实验设计清晰**：三个基准分别对应三个关键缺陷（历时连续性、因果耦合、归纳抽象），消融实验逐步剥离组件，验证了每个模块的贡献。
- **定性示例丰富**：展示了取代链（健身偏好演变）和跨域碰撞（园艺/教学→有机培养心智模型）的实例，直观说明系统行为。
- **开放讨论局限与伦理**：主动指出隐私、用户控制权、高风险使用警告等问题，体现了研究严谨性。

## 8. 不足与局限

- **实验覆盖有限**：
  - 仅评估英文聊天场景，未测试跨语言、多模态或实体代理。
  - 仅使用两个 LLM 后端（deepseek 和 kimi），未在更多基础模型上验证。
  - 未提供统计显著性检验（如置信区间、多次运行标准差）。
- **资源信息缺失**：未报告 GPU 资源、训练时间或 API 调用成本，不利于复现和算力评估。
- **系统2阈值敏感性**：`θ_beh` 和 `θ_sem` 在一个验证集上调优，在其他基准上可能不是最优；阈值固定而非学习，可能影响泛化。
- **架构假设限制**：
  - 跨域核心模式假设用户行为受少量认知模式支配，对某领域主导的用户增益有限。
  - 高域多样性时，双空间扫描的二次复杂度可能成为瓶颈（论文承认对绑定的成本）。
- **自然语言节点的不一致性**：模式、意图、核心模式以自然语言存储，继承提取 LLM 的输出变异性，不便于代数操作（如偏好向量集合交）。
- **安全性**：论文虽在伦理声明中讨论了隐私控制，但未在实验中评估用户干预或删除路径的有效性，也未测试对抗性输入可能导致的归纳偏差。
- **潜在偏差**：基准数据均为人工构造，与真实用户交互存在差距；系统在隐式推理上的提升可能部分来自基准设计偏好而非常规场景。
