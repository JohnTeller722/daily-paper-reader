## 摘要
记忆对于使大型语言模型（LLM）智能体能够处理长程推理任务至关重要。现有的记忆机制大多是集中式的，通常将检索到的信息和交互历史组织在单个模型上下文中。这种设计带来了一个根本性的权衡：扩展推理轨迹可能导致上下文过载，而激进的内容修剪可能造成不可逆的信息丢失。为了寻求更好的权衡，我们从人类认知系统中汲取灵感，特别是前额叶皮层（执行控制）和海马体（记忆管理）之间的功能互补性，这表明这种权衡并非固有，而可能源于集中式的记忆组织。为此，我们提出了ActiveMem，一个异构框架，将智能体记忆与核心推理过程解耦。具体来说，一个高层次规划器利用提炼的语义要点来执行推理，同时一个轻量级分布式记忆系统并行运行，在任务过程中主动积累和巩固这些要点。在BrowseComp-Plus和GAIA上的实验表明，ActiveMem以显著降低的开销实现了最先进的准确性，证明了分布式主动记忆在长程推理中的有效性。

## Abstract
Memory is essential for enabling large language model (LLM) agents to handle long-horizon reasoning tasks. Existing memory mechanisms are largely centralized, typically organizing retrieved information and interaction history within a single model context. This design imposes a fundamental trade-off: scaling reasoning trajectories risks context overload, whereas aggressive content pruning may result in irreversible information loss. Seeking a better trade-off, we draw inspiration from human cognitive systems, especially the functional complementarity between the prefrontal cortex (executive control) and the hippocampus (memory management), suggesting that such a trade-off need not be inherent, but may instead stem from centralized memory organization. To this end, we propose ActiveMem, a heterogeneous framework that decouples agent memory from the core reasoning process. Specifically, a high-level Planner utilizes distilled semantic gists to execute reasoning, while a lightweight, distributed memory system operates in parallel to actively accumulate and consolidate these gists throughout the task. Experiments on BrowseComp-Plus and GAIA show that ActiveMem achieves state-of-the-art accuracy with significantly reduced overhead, demonstrating the effectiveness of distributed active memory for long-horizon reasoning.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：**解耦记忆与推理**，设计一个“Planner + 分布式记忆系统”的架构。Planner（大模型，如Qwen3.5-397B-A17B）负责高层次推理和查询生成，只维护一个紧凑的推理状态（原始问题 + 最近K步交互历史 + 上一步返回的蒸馏记忆）。分布式记忆系统包含三个核心组件：
  - **Memory Shards**：持久化存储层，固定数量的逻辑分片，每个分片以文档ID为键，存储该文档的蒸馏要点（gist）和查询历史。
  - **Memorizer**：轻量级小模型（如4B），并行处理检索到的文档，基于Planner的子查询（query）生成查询条件化的浓缩要点（公式：`gc = ω(c, q)`）。通过SFT训练使其学会简洁、内容相关的蒸馏。
  - **Operator**：控制层，负责将Planner的查询与检索文档转化为记忆任务，路由到合适的分片，并管理记忆复用与异步合并。核心操作包括：
    - 判断是否为新查询（SIMILAR / NEW），若与历史查询相似则直接复用已有gist，避免重复蒸馏；
    - 对新查询触发Memorizer蒸馏，产生新的gist；
    - 异步合并同一文档的不同查询gist，保留事实、消除冗余。
- **关键技术细节**：
  - Planner的推理状态维护：`st = (x, ht, m_{t-1})`，其中`ht = Trim(ht-1 ∪ {at, ot})`，只保留最近K步交互，丢弃早期内容（但gist已存入Shards）。
  - 自动训练数据构建：在BrowseComp-Plus训练集上运行完整ActiveMem框架，收集12,000个真实query-document对，使用gpt-oss-120b作为教师模型生成gist，用于训练Memorizer。
  - 训练目标：条件下一个token预测损失（公式5），使Memorizer学习生成简洁、文档接地、查询条件的gist。
  - 推理流程（Algorithm 1）：每步Planner发出查询集Qt；检索文档后路由到并行Memorizer；对于每个文档，Operator判断miss/hit（SIMILAR）/NEW，相应处理；收集所有gist组装成observation，Trim后追加到历史。

### 6. 论文的主要结论与发现

- **精度-效率最优**：ActiveMem在BrowseComp-Plus上取得最高LasJ（0.79）和最高ACT（0.785），在GAIA上取得最高LasJ（0.62）且PFLOPs最低（187）。相比集中式记忆方法（如MemoBrain），ActiveMem在BrowseComp-Plus精度提升0.16（0.63→0.79），在GAIA上计算量降低63.7%（516→187 PFLOPs）。
- **难度越高，优势越明显**：在Hard子集上相比最优baseline（Context-Folding）相对提升22.2%（0.36→0.44），表明解耦记忆在检索密集的复杂任务中收益更大。
- **记忆分片减少冗余**：去除Memory Shards后Memorizer PFLOPs上升17.6%（1478→1739），且由于信息丢失导致LasJ下降（0.786→0.750），说明Distillation与shards互补。
- **更强的Memorizer提升推理质量**：SFT训练的Memorizer-4B比Instruct变体显著提升精度（0.667→0.786），同时Planner成本更低，证明更精确的gist减少了下游推理负担。
- **计算分配优化**：Memorizer占68.9%总PFLOPs，Planner仅28.3%，通过将token密集型处理卸载到小模型，实现测试时扩展更有利（更多token但总FLOPs低）。
