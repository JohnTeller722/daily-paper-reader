## 摘要
大型语言模型（LLM）智能体因其固有的无状态性，在处理长时任务时面临困难，所有与任务相关的信息必须编码在日益增长的输入上下文中。这导致推理质量下降、推理成本增加和延迟升高，亟需高效的工作记忆机制。然而，现有方法要么依赖有损压缩，要么基于相似性检索，往往无法捕捉多步智能体任务所需的时间结构和因果依赖关系。本文提出HORMA，一种层级组织与检索记忆智能体，它将经验组织成类似文件系统的层级结构，其中总结实体与对应的原始轨迹相链接，从而在不丢失细节信息的情况下实现高效访问。HORMA将工作记忆分解为两个阶段：结构化记忆构建和基于导航的检索。构建模块通过区分由信息缺失导致的失败和由上下文误导或过载导致的失败，迭代地优化经验的构建方式。导航模块使用一个通过强化学习训练的轻量级智能体遍历层级结构，选择最小且充分的上下文，从而缩短关键执行路径上的延迟。在ALFWorld、LoCoMo和LongMemEval上，HORMA在受限的上下文预算下提升了任务性能，同时在长对话任务中最多仅需基线token使用量的22.17%。与现有方法相比，它始终实现了更好的效率-性能权衡，并能有效泛化到未见任务。

## Abstract
Large language model (LLM) agents struggle with long-horizon tasks due to their inherent statelessness, requiring all task-relevant information to be encoded in growing input contexts. The resulting degraded reasoning quality, increased inference cost, and higher latency necessitate efficient working memory mechanisms. However, existing approaches either rely on lossy compression or similarity-based retrieval, which often fail to capture temporal structure and causal dependencies required for multi-step agentic tasks. In this work, we present HORMA, a Hierarchical Organize-and-Retrieve Memory Agent that organizes experience into a file-system-like hierarchical structure, where summarized entities are linked to the corresponding raw trajectories, enabling efficient access without losing detailed information. HORMA decomposes working memory into two stages: structured memory construction and navigation-based retrieval. The construction module iteratively refines how experiences are structured by distinguishing between failures caused by missing information and those caused by misleading or overloaded context. The navigation module retrieves task-relevant context by traversing the hierarchy using a lightweight agent trained with reinforcement learning to select minimal yet sufficient context, thereby reducing latency along the critical execution path. Across ALFWorld, LoCoMo, and LongMemEval, HORMA improves task performance under constrained context budgets while requiring at most 22.17% of the baseline token usage in long conversation tasks. Compared to existing methods, it consistently achieves better efficiency-performance trade-offs and generalizes effectively to unseen tasks.

- **问题**：LLM智能体在处理长时任务（如多轮交互、长对话）时，由于无状态性，需要将所有历史信息编码在持续增长的输入上下文中。这导致推理质量下降（信息稀释、lost-in-the-middle）、推理成本飙升、延迟增加。
- **现有方法局限**：

  - 基于语义相似性的扁平检索无法捕捉时间层级和因果依赖，检索结果常存在时间不一致或上下文无关。
- **需求**：需要一种既能选择性保留信息，又能将积累经验组织为可复用、语义一致的结构化记忆，以提升下游任务性能。

## 2. 方法论：核心思想、关键技术细节

- **整体框架**：HORMA（Hierarchical Organize-and-Retrieve Memory Agent）将工作记忆显式解耦为两个模块：
  1. **层级管理智能体（Memory Manager）**：负责将原始轨迹组织成文件系统式层级结构（目录、文件、摘要节点），并链接到原始轨迹。
  2. **层级检索智能体（Retrieval Agent）**：通过Bash工具（`ls`, `cd`, `grep`, `cat`, `select`, `done`）导航该层级结构，以最小且充分的上下文支持主智能体决策。

- **关键技术细节**：
  - **记忆构建**：
    - 利用前沿LLM（如Claude Sonnet 4.5）的语义抽象能力，通过递归技能精炼（Recursive Skill Refinement）迭代优化管理策略。
    - 通过对比成功/失败轨迹，区分两类失败：
      - **外源性失败**：结构化记忆导致信息丢失（原始历史成功，HORMA失败）。
      - **内源性失败**：结构化记忆有助于过滤噪声（HORMA成功，原始历史失败）。
    - 生成反馈并更新记忆管理技能，形成技能库。
  - **记忆检索**：
    - 将检索视为在文件系统上的序列决策问题，使用扩展的动作空间（`select` 添加已确认内容，`done` 终止检索）。
    - 使用**GRPO（Group Relative Policy Optimization）** 训练轻量级检索智能体（基于Qwen 3.5 4B）。
    - 奖励函数：证据重叠奖励 $J(C_t, E) = \frac{|C_t \cap E|}{|C_t \cup E|}$，鼓励检索精确且紧凑的上下文。
  - **整体工作机制**：
    - 记忆管理离线或异步更新，不影响主智能体推理路径。
    - 检索在线执行，通过导航层级结构获取所需上下文，主智能体仅基于检索到的上下文生成动作。

## 6. 主要结论与发现

- **性能提升**：HORMA在三个基准上，在受限上下文预算下均达到最高成功率或L-J得分。ALFWorld小限制下56.7%（优于次优27.0%），大限制下73.9%（优于次优71.6%）。LoCoMo上L-J得分51.6%（接近无限制的55.9%）。LongMemEval上55.9%（超过所有基线）。
- **效率收益**：HORMA的token使用量仅为基线方法的3.07%~22.17%（LoCoMo）和1.24%~16.19%（LongMemEval）。
- **泛化能力**：基于Qwen 3.5 4B的RL训练检索器在完全未见领域（ALFWorld、LongMemEval）上表现出色，LongMemEval性能达到58%，超越Claude Sonnet 4.5检索器（55.9%）。
- **记忆构建是关键瓶颈**：即使替换强大检索器，弱管理模型（Qwen）仍大幅落后，说明结构化记忆的质量直接决定了检索上限。
- **导航检索优于语义检索**：在时间敏感任务中，HORMA显著减少非推理错误（如时间陈旧、无关检索）。
- **技能库增长与性能正相关**：经过4轮迭代，技能库扩展至63个技能，任务得分持续提升。

## 7. 优点

1. **解耦设计**：将记忆构建与检索分离，分别优化，避免了端到端RL中的信用分配问题。
2. **结构化记忆**：文件系统式层级结构提供了可解释性、溯源能力和高效导航，优于扁平检索。
3. **轻量级检索器**：仅用4B参数的Qwen经RL训练后能在低资源下高效导航，且跨域泛化强。
4. **技能演化机制**：通过对比轨迹自动生成可复用的记忆管理技能，无需人工设计，且可跨任务迁移。
5. **直接优化检索质量**：使用证据重叠奖励提供细粒度反馈，优于稀疏任务奖励。
6. **效率-性能权衡**：在极低token预算下仍能保持或超越多数基线，适用于实际部署。
