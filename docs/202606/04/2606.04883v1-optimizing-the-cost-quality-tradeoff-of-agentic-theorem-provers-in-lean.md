## 摘要
大型语言模型（LLMs）越来越多地被用于生成 Lean 形式化证明的工作流程中。这些工作流程通常将问题分解为更小的引理，采样多个证明尝试，并利用编译器反馈来指导搜索。然而，它们可能变得过于昂贵，经常在最终失败的尝试上投入大量计算。在这项工作中，我们通过一个由数据平面和控制平面组成的动作路由智能体来解决这个问题。数据平面生成自然语言的引理分解，将其形式化为 Lean 语言，并对结果定理和引理目标进行证明尝试的采样。控制平面观察之前的失败 Lean 尝试，估算另一次尝试的成功可能性和成本，并决定是继续证明当前目标还是从新的分解重新开始。在 PutnamBench 的一个子集上，我们的智能体平均比固定步长基线降低了 25.8% 的成本，在保持性能的同时使用了显著较少的计算。这些结果表明，失败的 Lean 轨迹为智能定理证明中的成本感知资源分配提供了可操作的信号。

## Abstract
Large language models (LLMs) are increasingly used in workflows for generating formal proofs in Lean. These workflows often decompose problems into smaller lemmas, sample many proof attempts, and use compiler feedback to guide search. However, they can be prohibitively expensive, often spending substantial compute on attempts that ultimately fail. In this work, we address this problem with an action routing agent that consists of a data plane and a control plane. The data plane generates natural-language lemma decompositions, formalizes them in Lean, and samples proof attempts for the resulting theorem and lemma targets. The control plane observes previous failed Lean attempts, estimates both the likelihood of success and cost of another attempt, and decides whether to continue proving the current target or restart from a new breakdown. On a subset of PutnamBench, our agent decreases the cost by $25.8\%$ over a fixed-step baseline on average, preserving performance while using substantially less compute. These results suggest that failed Lean trajectories provide actionable signals for cost-aware resource allocation in agentic theorem proving.

### 论文核心问题与整体含义（研究动机和背景）

- **问题**：当前基于大型语言模型（LLM）的 Lean 形式化定理证明工作流（如递归分解、采样证明尝试）虽然能显著提升性能，但成本极高——大量计算被浪费在最终失败的尝试上。固定步长策略（fixed-step policy）对所有问题分配相同的预算，导致低效的成本-质量权衡。
- **动机**：现有的智能体定理证明器主要关注性能提升，而忽略了效率优化。作者希望通过动态路由策略，利用失败尝试的反馈信号，实现成本感知的资源分配，在保持性能的同时大幅降低计算消耗。

### 论文提出的方法论

- **核心思想**：提出一种 **动作路由智能体（Action Routing Agent）**，将系统分为两个平面：
  - **数据平面（Data Plane）**：负责证明生成——分解问题为自然语言引理、形式化为 Lean 代码、采样证明尝试，并记录轨迹。
  - **控制平面（Control Plane）**：负责动态路由决策——观察历史失败轨迹，估算下一次尝试的成功概率（质量 $ \hat{q}(s) $）和计算成本 $ \hat{c}(s) $，然后基于效用函数 $ \tau(s) = \hat{q}(s) - \lambda \hat{c}(s) $ 决定是继续尝试（ATTEMPT）还是终止并重启（TERMINATE）。
- **关键技术细节**：
  - **质量估计**：使用逻辑回归模型，输入特征包括证明相似度（修复变量名后的平均模糊字符串比率）、错误多样性（不同编译错误占比）以及尝试次数。
  - **成本估计**：将输出 token 数量作为计算成本的代理，用历史平均成本预测下一次尝试成本。
  - **超参数 $\lambda$**：控制成本惩罚力度，小 $\lambda$ 倾向继续尝试，大 $\lambda$ 倾向提前终止，可沿成本-质量前沿曲线调优。
  - **算法流程**：初始采样两次尝试后，每次决策点根据当前状态 $s$ 计算 $\tau(s)$，若为正则继续尝试，否则终止当前目标并尝试新的分解（最多 $n_b$ 次分解）。
- **扩展性**：该方法可推广到更大动作空间（如切换模型、自我修正等），只需将效用函数推广为 $\pi(s) = \arg\max_{a} [\hat{q}(a,s) - \lambda \hat{c}(a,s)]$。

### 论文的主要结论与发现

1. **路由智能体显著提升效率**：在相等性能下平均降低 **25.8%** 计算成本；在相等成本下提升 **7.8%** 准确率。
2. **固定步长策略存在显著效率改进空间**：许多尝试被分配给不可能成功的目标。
3. **失败轨迹提供了有效信号**：特征（误差多样性、证明相似度、尝试次数）与下一次成功概率相关，逻辑回归能有效捕捉。
4. **与 oracle 尚有差距**：零噪声 oracle 可实现 59.9% 成本降低，本文方法为 25.8%，说明特征和模型仍有改进空间。
5. **数据平面本身有效**：相比直接全证明生成，数据平面架构显著提升性能（几乎匹配更大模型）。

### 优点

- **方法创新**：首次将路由/级联思想应用于智能体定理证明，通过轻量级模型动态决策，概念清晰且可扩展。
- **实用性强**：直接降低实际部署成本，且保持性能；控制平面与数据平面解耦，易于替换或升级。
- **实验设计严谨**：对比了固定基线和 oracle 上限，进行了噪声扰动分析和特征消融，量化了不同因素贡献。
- **开源承诺**：提供了代码仓库链接，促进可复现性。

### 不足与局限

- **基准规模小**：仅使用 PutnamBench 子集（85 题，测试集 43 题），泛化性需在更大基准（如 MiniF2F、Matharena）上验证。
- **与 oracle 差距大**：当前特征和估计器未能充分利用轨迹信息，可能存在过拟合或欠拟合风险。
- **动作空间有限**：仅支持 ATTEMPT 和 TERMINATE，未探索模型切换、自修正等更丰富动作。
- **成本模型简化**：仅用 token 数代理成本，未考虑推理延迟、编译时间等实际因素。
- **训练数据收集成本高**：质量估计器需要大量轨迹数据，对于新问题可能缺乏泛化能力。
- **资源估计出自单一实验**：GPU 小时数仅为近似估计，未严格报告多次运行方差。
