## 摘要
现有的大语言模型路由方法通常将模型对查询的单个响应作为其能力标签来训练路由器。然而，由于大语言模型的生成本质上具有随机性，这种单次监督仅提供了查询-模型对行为的噪声观测，而非可靠的能力估计。我们表明，这种假设会将系统噪声引入路由监督，使得学习到的路由策略可靠性降低。为解决该问题，我们提出了DARS（分布感知路由监督）框架，该框架从模型行为的分布视角构建路由监督。不同于依赖单一生成响应，DARS同时考虑输入端和输出端的不确定性，捕捉语义等价的查询表述和随机生成如何影响模型性能。基于这些分布感知的观测，DARS为路由构建了更可靠的监督信号。跨不同任务的实验表明，单次标签可能误导模型选择，而分布感知监督提供了更稳定的标签并改进了学习到的路由行为。我们的结果表明，可靠的大语言模型路由应超越单次响应观测，而基于查询级别的模型能力分布。

## Abstract
Existing LLM routing methods typically treat a model's single response to a query as its capability label for training routers. However, because LLM generation is inherently stochastic, such single-shot supervision provides only a noisy observation of a query-model pair's behavior rather than a reliable capability estimate. We show that this assumption introduces systematic noise into routing supervision, making learned routing policies less reliable. To address this issue, we propose DARS (Distribution-Aware Routing Supervision), a framework that constructs routing supervision from a distributional view of model behavior. Instead of relying on a single generated response, DARS considers uncertainty from both the input side and the output side, capturing how semantically equivalent query formulations and stochastic generations affect model performance. Based on these distribution-aware observations, DARS builds more reliable supervision signals for routing. Experiments across diverse tasks show that single-shot labels can be misleading for model selection, while distribution-aware supervision provides more stable labels and improves learned routing behavior. Our results suggest that reliable LLM routing should move beyond single-response observations and be grounded in query-level model capability distributions.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的大语言模型路由方法在训练路由器时，通常将模型对某个查询的**单次生成响应**视为该模型在该查询上的能力标签（single-shot supervision）。然而，LLM 的生成本质上具有随机性，这种单次观测只是噪声样本，无法可靠反映模型真实能力，从而导致路由策略不稳定、不可靠。
- **研究动机**：作者通过诊断实验发现，单次标签在三个指标（结果不稳定性、优胜模型翻转率、单次 vs. 分布感知标签不一致率）上均表现出高波动性，且不同任务的不确定性来源不同（如GPQA和MATH-500以输出端不确定性为主，DROP-800则输入端和输出端不确定性相当）。进一步地，基于单次标签训练的路由器在不同采样下性能方差显著，说明噪声会传播到最终策略。
- **整体含义**：LLM 路由应当从基于单次样本的监督转向基于**查询级模型能力分布**的监督，以建立更可靠、稳定的路由策略。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：提出 **DARS（Distribution-Aware Routing Supervision）** 框架，通过多次观测来估计每个查询-模型对的**能力分布**，从而构建更稳定的监督信号。
- **关键技术细节**：
  1. **重复观测构建**：对每个训练查询，使用一个强语言模型（如GPT-4o）生成 N 个语义等价的**重写查询**（模拟输入端不确定性）；然后对每个重写查询和每个候选模型进行 M 次**随机解码**（模拟输出端不确定性），得到一个 N×M 的观测矩阵。
  2. **分布能力估计**：从观测矩阵中计算三个信号：
     - 期望质量 \( \mu_q(x,m) \)：所有观测质量分数的均值。
     - 期望成本 \( \mu_c(x,m) \)：所有观测成本的均值。
     - 性能风险 \( \sigma_q(x,m) \)：质量分数的标准差（反映总体变异性）。
  3. **风险感知效用**：组合上述信号得到每个查询-模型对的效用：
     \[
     U(x,m) = \mu_q(x,m) - \lambda \mu_c(x,m) - \beta \sigma_q(x,m)
     \]
     其中 \(\lambda\) 是成本系数，\(\beta\) 是风险系数。
  4. **路由策略学习**：DARS 提供监督信号的方式灵活（可支持回归、分类、排名、偏好等路由器架构），例如可转换为软分类目标或直接作为效用标签。
- **算法流程**（文字说明）：
  - 对每个训练查询：生成 N 个重写 → 对每个重写和每个模型执行 M 次解码 → 收集所有观测 → 计算 \(\mu_q, \mu_c, \sigma_q\) → 构造风险感知效用 \(U\) → 基于 \(U\) 生成训练标签（如最佳模型、软目标等） → 训练路由器（可复用任意现有路由器架构，仅替换监督信号）。

## 6. 论文的主要结论与发现

1. **单次标签不可靠**：单次标签在结果、优胜模型和标签三个层面均不稳定，且不确定性来源因任务而异（GPQA、MATH-500以输出端不确定性为主，DROP-800两端相当）。
2. **标签噪声传播到路由器**：100个单次采样训练出的路由器性能方差显著，说明监督噪声影响最终策略。
3. **DARS 提供更稳定标签并提升路由性能**：在所有路由器架构上，DARS 几乎一致地优于单次监督，特别在 GPQA 上升幅度最大，在 MATH-500 上使 MIRT 从弱变强。
4. **组件互补**：同时使用输入端和输出端观测、并引入风险项，能取得最佳效果；仅用单一方向或去除风险项均降低性能。
5. **样本效率高**：3×3 的观测协议已接近 5×5 的效果，说明 DARS 无需过多采样即可有效。
6. **风险系数不敏感**：\(\beta\) 在较宽范围内性能稳定，推荐 \(\beta=0.2\)。

- **方法设计合理**：DARS 通过重写和重复解码估计能力分布，并引入风险项，概念清晰且技术实现简洁。
