## 摘要
大型语言模型（LLM）作为使用工具的智能体展现了潜力，但在需要记忆、组织和复用知识的长期任务中仍受限。先前的记忆方法旨在解决这一问题，但主要聚焦于存储事实信息。近期关于程序性记忆的工作改进了任务复用，然而往往简化为重放过去的成功经验，未能处理失败案例或在线可扩展性。我们提出了一种统一且自动化的记忆框架，将语义记忆、情景记忆和程序性记忆整合到结合短期与长期存储的双层设计中。采用包含行动者、记忆和评论者智能体的多智能体架构，实现了自动记忆生成、奖励标注和自适应检索。长期记忆通过基于奖励的评估、合并和剪枝进行管理，确保可扩展性和持续改进。跨多种环境的实验表明，与现有基线相比，我们的方法提升了长期多轮任务的鲁棒性和成功率。这项工作凸显了全面的自适应记忆对于推进基于LLM的智能体的重要性。

## Abstract
Large Language Models (LLMs) show promise as tool-using agents but remain limited in long-horizon tasks that require remembering, organizing, and reusing knowledge. Prior memory approaches aim to resolve the situation, but mainly focus on storing factual information. Recent work on procedural memory improves task reuse, yet often reduces to replaying past successes without addressing failure cases or online scalability. We introduce a unified and automatic memory framework that integrates semantic, episodic, and procedural memory in a bi-level design combining short-term and long-term stores. A multi-agent architecture with actor, memory, and critic agents enables automatic memory generation, reward annotation, and adaptive retrieval. Long-term memory is managed through reward-based evaluation, merging, and pruning, ensuring scalability and continual improvement. Experiments across various environments show that our approach improves robustness and success on long multi-turn tasks compared to existing baselines. This work highlights the importance of comprehensive, adaptive memory for advancing LLM-based agents.

## 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：将认知科学中的语义记忆、情景记忆和程序性记忆整合到一个双层（短期/长期）记忆结构中，并通过多智能体架构（演员、评论家、记忆智能体）实现自动记忆生成、奖励标注和自适应检索、合并与剪枝。
- **关键技术细节**：
  - **记忆分类**：
    - **语义记忆（M_S）**：存储关于环境和任务的事实与通用知识（通过LLM总结）。
    - **情景记忆（M_E）**：存储过去交互事件的摘要（通过LLM总结）。
    - **程序性记忆（M_P）**：存储从过去行动中提取的决策指导。每个动作附带预期结果，评论家智能体在后续观察后对比实际结果，生成奖励（0或1）和反思，形成程序性记忆条目。
  - **双层记忆架构**：
    - **短期记忆（STM）**：每个任务内维护的上下文记录，采用类似程序栈的结构进行上下文压缩（包含当前子目标、计划等）。任务结束时清空。
    - **长期记忆（LTM）**：跨任务持久存储。由记忆智能体管理，使用稠密检索（语义/情景）和结合有效性评分与上下文相似度的加权检索（程序性）。管理策略包括：基于阈值ε的频次剪枝（低频删除）、高频共现合并（基于检索统计）。程序性记忆条目维护一个有效性参数v_m ∈ [0,1]，通过轻量级模型（假设奖励由帮助性变量的随机过程产生）并采用EM算法更新。
  - **多智能体架构**：
    - **演员智能体**：与环境和用户交互，基于LLM策略选择动作，维护短期记忆，使用记忆规划工具（Plan for new task, Add subgoal, Conclude subgoal, Think, Take action）。每个动作需明确预期结果。
    - **记忆智能体**：管理长期记忆存储，负责检索和管理（合并、剪枝、更新评分）。
    - **评论家智能体**：接收演员的半成品记忆（动作上下文、动作、预期结果），等待相关观察到达后进行批判性总结：生成奖励、反思、更新记忆条目的有效性参数，并反馈给记忆智能体。
- **算法流程**（文字描述）：
  - **演员智能体循环**：每轮接收观察→报告给评论家→从记忆智能体检索相关记忆→基于上下文和记忆选择动作并设定预期→更新短期记忆→将半成品记忆发给评论家。
  - **评论家智能体循环**：维护队列，接收半成品记忆和观察；当某动作的所有相关观察收集完毕时，生成奖励和反思，创建新程序性记忆条目并更新已检索记忆的评分。

## 6. 主要结论与发现
- **性能提升**：AdMem在大多数领域显著优于ReAct和AWM，尤其在AlfWorld（完成度63.4% vs 49.3%）、PDDL（76.7% vs 33.3%）、Tool-query Academic（94.7% vs 70.0%）等。在部分领域（WebShop, ScienceWorld）与ReAct持平或略降，但认为记忆系统未严重损害性能。
- **长期益处**：在Jericho上多轮测试（同一任务集重复3个epoch）显示AdMem完成度从45%提至60%，而仅LTP（无短期规划）从20%提至30%，说明完整框架支持持续自我改进。
- **消融发现**：短期规划（STP）提升单轮进度但无法跨任务；长期记忆（LTP）提升跨任务复用但早期有性能退化；完整AdMem在长期和短期间取得平衡。
- **核心贡献**：综合、自适应的记忆（包括程序性记忆的奖励驱动评估与管理）是提升LLM智能体长期任务能力的关键。

## 7. 优点
- **理论到实践的桥梁**：首次将认知架构中的三类记忆与短期/长期双层存储系统性地集成到可运行的LLM智能体中，且具有自动化和可扩展性。
- **多智能体设计**：actor-critic分离，critic负责异步生成记忆和分配奖励，不阻塞actor，支持在线持续学习。
- **奖励驱动的记忆管理**：引入程序性记忆有效性参数和EM更新，以及基于检索统计的合并/剪枝策略，实现动态优化，避免记忆膨胀。
- **上下文压缩**：采用栈式子目标管理，类似程序执行，有效限制上下文长度，提高策略效率。
- **失败案例处理**：通过critic对实际结果与预期结果的对比，不仅能记录成功，也能从失败中学习，这是此前程序性记忆工作的弱点。
- **实验在多领域验证**，并提供了消融和多轮epoch分析。

- **记忆系统复杂度**：需要精细设计的提示词和工具集（plan, subgoal等），对LLM的指令遵循能力要求高，可能在较弱模型上效果下降。
