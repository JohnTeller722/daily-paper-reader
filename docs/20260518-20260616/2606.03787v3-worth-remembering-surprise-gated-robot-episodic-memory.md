## 摘要
解决通用任务的机器人需要能够将指令与过去的经验相结合，因为人类在给出任务时可能会提到值得注意的过去事件（例如，“带我去昨天发生化学品泄漏的地方”）。由于记忆限制使得存储所有过去事件不可行，长期机器人记忆必须具有选择性，理想情况下只保留那些对未来任务具有高实用性的情景。然而，对于通用机器人而言，未来任务通常不是先验给定的。为了选择具有通用实用性的记忆，我们提出贝叶斯惊喜作为记忆形成的门控机制。我们提出了一种方法，在由V-JEPA-2提供的语义丰富且与部署无关的潜在空间中计算惊喜。通过使用我们的门控情景记忆来增强基于4D场景图的空间记忆，我们在机器人问答方面显示出相对于最先进基准的一致改进，在时间、空间和二元问题上比先前的机器人记忆方法提高≥12%，并在事件分割任务中以无监督因果方法超越了监督和非因果方法的性能。

## Abstract
Robots solving generalist tasks need to be able to ground instructions in their past experience, since humans may refer to notable past events when giving a task (e.g., ``Take me to where the chemical spill happened yesterday''). Since memory limits make storing all past events infeasible, long-term robot memory must be selective, ideally retaining only those episodes with high utility for future tasks. However, future tasks are not typically given a priori for generalist robots. To select generically useful memories, we propose Bayesian surprise as a gating mechanism for memory formation. We present an approach to compute surprise in a semantically rich deployment-agnostic latent space provided by V-JEPA-2. Using our gated episodic memory to augment 4D scene graph-based spatial memory, we show a consistent improvement over state-of-the-art benchmarks in robot question answering, outperforming prior robot memory methods by $\geq12\%$ for temporal, spatial, and binary questions, and surpassing the performance of supervised and non-causal methods with an unsupervised causal method in event segmentation tasks.

## 2. 方法论

### 核心思想
- 使用**贝叶斯惊喜**作为记忆门控信号：计算观测前后预测分布之间的KL散度，高惊喜处存储情景记忆。

### 关键技术细节
- **特征提取**：将连续帧输入V-JEPA-2编码器（滑动窗口M=64帧），输出压缩时空特征zt ∈ ℝ¹⁰²⁴。
- **局部预测模型**：对过去W=64个特征拟合对角高斯分布pt = ∏_d N(μ_W[t,d], σ²_W[t,d])，以运行均值和标准差表示。
- **惊喜计算**：采用ℓ₁代理形式（等效于高斯KL散度，附录A推导）：
  s(t) = (1/D) ∑_d |zt[d] - μ_W[t,d]| / σ_W[t,d]
- **触发阈值**：使用中位数绝对偏差（MAD）的鲁棒阈值 τ = med(s) + γ·(1/Φ⁻¹(0.75))·MAD(s)，其中γ=1.0。再经非极大值抑制去重。
- **存储内容**：触发时刻的8帧、惊喜分数、联合视觉-文本嵌入（用于后续检索）。
- **集成**：将惊喜门控情景记忆作为附加层叠加到DAAAM的4D场景图上，下游agent可通过最大文本-图像相似度检索相应视觉片段。

## 6. 主要结论与发现

- 贝叶斯惊喜门控的情景记忆**显著提升**机器人长期问答性能：问题准确率提高12.0%，位置误差降低12.4%，时间误差降低15.7%。
- 均匀或随机情景记忆虽对二元问题有帮助，但会因冗余视觉信息降低时空问题质量。惊喜门控在保存高细节事件（如开门的人帽子的颜色）方面尤其有效。
- 在Kinetics-400通用事件边界检测上，本文无监督在线方法（平均F1=0.833）**超越**所有监督/非因果离线方法（最佳PC为0.817），表明该方法不仅适用于机器人，也具备通用视频理解能力。

## 7. 优点

- **认知科学启发**：将贝叶斯惊喜从人类记忆研究直接转化为机器人记忆门控，具有理论依据。
- **无监督且因果**：无需人工标注，无需未来帧信息，适合在线部署。
- **部署无关**：V-JEPA-2在大规模通用视频上预训练，无需针对特定环境微调。
- **效率高**：仅在惊喜峰值存储（约1.7%帧），省资源。
- **任务通用**：同时对机器人问答和通用事件分割有效，说明选择的事件具有持久效用。
- **鲁棒阈值**：使用MAD（中位数绝对偏差）对长尾分布稳定，与V-JEPA的ℓ₁训练损失一致。

## 8. 不足与局限

- **预测模型简单**：V-JEPA-2本身是非因果的，仅用对角高斯作为因果替代，表达能力有限。作者指出未来的V-JEPA-2-AC等因果变体可能更好。
- **存储方式原始**：当前仅存储视觉帧作为检索项，未用视频/文本联合嵌入来捕捉事件时间演变。
- **重复触发问题**：周期性出现的新颖物体（如反复出现的人）仍会持续触发存储，缺乏习惯化机制。
- **TAPOS数据集表现不佳**：由于事件边界多为语义性（如运动动作转换），在线惊喜不如离线深度监督方法。这暗示方法对纯语义边界不够敏感。
- **依赖性**：需要多模态大模型（GPT-5-mini）进行推理，增加开销，且结果受LLM能力影响。
- **参数固定**：阈值γ目前为1.0，未自适应调整。
