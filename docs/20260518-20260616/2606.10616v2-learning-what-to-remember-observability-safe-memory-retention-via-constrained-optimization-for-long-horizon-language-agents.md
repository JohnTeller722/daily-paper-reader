## 摘要
长程语言代理积累的观测、推理轨迹和检索事实会超过其有限的上下文窗口，使得记忆保持成为一个基本的资源分配问题。现有的记忆系统通过启发式评分、检索优化或学习压缩来改进管理，但大多将记忆保持视为局部决策问题，并未在现实的可观测性约束下显式建模其长期后果。为填补这一空白，我们将记忆保持形式化为一个受约束的随机优化问题，具有明确的预算可行性、证据效用以及延迟成本（包括遗漏惩罚、重新获取延迟和过时信息风险）。随后，我们提出OSL-MR（Observability-Safe Learning for Memory Retention），一种新颖的框架，强制在线可观测特征与离线可用监督（OAS）严格分离。OSL-MR结合了从实现证据监督中训练的证据学习器与混合评分启发式，后者既可作为可部署的在线安全基线，又可作为学习用的结构化归纳先验。由此产生的策略直接从交互数据中学习查询条件化的证据价值，同时在同一可观测性约束下保持可部署性。在LOCOMO和LongMemEval上的实验表明，OSL-MR在记忆预算紧张时尤其持续优于基于最近性的方法、生成式代理风格评分及其他启发式基线。混合评分先验在保持召回率的同时进一步提高了精确度，敏感性分析表明在广泛的成本配置下具有鲁棒性。

## Abstract
Long-horizon language agents accumulate observations, reasoning traces, and retrieved facts that exceed their finite context windows, making memory retention a fundamental resource-allocation problem. Existing memory systems improve management through heuristic scoring, retrieval optimization, or learned compression, but largely treat retention as a local decision problem and do not explicitly model its long-term consequences under realistic observability constraints. To fill this gap, we formulate memory retention as a constrained stochastic optimization problem with explicit budget feasibility, evidence utility, and delayed costs including miss penalties, reacquisition delays, and stale-information risk. We then propose OSL-MR (Observability-Safe Learning for Memory Retention), a novel framework that enforces a strict separation between online-observable features and offline-available supervision (OAS). OSL-MR combines an evidence learner trained from realized evidence supervision with a Mixed-Score heuristic that serves both as a deployable online-safe baseline and as a structured inductive prior for learning. The resulting policy learns query-conditioned evidence value directly from interaction data while remaining deployable under the same observability constraints. Experiments on LOCOMO and LongMemEval show that OSL-MR consistently outperforms recency-based methods, Generative Agents-style scoring, and other heuristic baselines, particularly under tight memory budgets. The Mixed-Score prior further improves precision while preserving recall, and sensitivity analysis demonstrates robustness across a wide range of cost configurations.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将记忆保留建模为**长时域顺序决策问题**，在硬预算约束下最大化期望累积奖励，并严格区分**在线可观测特征**（查询上下文、记忆元数据、交互历史）与**离线可用监督（OAS）**（金标准证据、答案内容、真实新鲜度等）。
- 提出 **OSL-MR（Observability-Safe Learning for Memory Retention）** 框架，包含三个紧密耦合的组件：
  1. **约束优化问题形式化**：定义每步奖励（命中奖励、全覆盖奖金、存储成本、遗漏惩罚、重新获取惩罚、过时惩罚）和硬预算约束，目标最大化累积奖励。
  2. **混合评分（Mixed-Score）启发式**：结合多项在线可观测特征（时间、相关性、上下文、风险）和尺寸惩罚，提供一个完全可部署的冷启动策略，同时作为学习阶段的归纳先验。
  3. **证据学习器（Evidence Learner）**：使用金标准证据标签（y_evid = 1 若记忆属于当前查询的证据集）进行监督训练。该学习器将混合评分作为输入特征之一，输出每个记忆的效用logit，然后通过预算约束解码器选择保留子集。

### 关键技术细节
- **在线/离线分离**：部署时策略只能使用在线可观测特征；OAS仅用于训练和评估，保证决策真实可行。
- **新鲜度代理**：采用基于记忆类型（稳定/临时）和步数的指数衰减估计新鲜度，避免了需要真实新鲜度标签。
- **训练目标**：使用加权二分类交叉熵训练证据学习器，学习证据成员关系。论文论证该代理足以隐式编码奖励结构（命中+避免处罚）。
- **部署流程**：冷启动阶段仅用混合评分并记录交互日志，收集足够数据后离线训练证据学习器，然后冻结部署替换启发式。

> **算法流程简述**：
> 1. 初始化空数据集。
> 2. 在每个交互环境中，对于当前时间步的记忆池，计算在线特征和混合评分，形成特征向量φ。
> 3. 使用混合评分进行选择（冷启动），并记录当前状态、特征、金标准证据标签y_evid。
> 4. 收集完整日志后，用加权交叉熵训练证据学习器f_θ。
> 5. 部署时，改为使用f_θ计算效用，再通过预算约束解码器选择保留子集。

## 6. 论文的主要结论与发现

1. **启发式方法不足**：近因、GA、Mixed-Score均会填满预算但证据F1低，尤其在紧预算下。
2. **直接证据监督优于行为克隆**：OSL-MR（使用金标准证据标签）在所有配置下优于BC-learner（模仿教师），说明真实证据标签比模仿改进后的启发式更有效。
3. **混合评分先验提升精确度而不损失召回**：移除先验后，精确度下降（最高20%），召回率几乎不变，占用率上升，表明先验帮助避免保留低效用记忆。
4. **优化目标与证据质量一致**：奖励排名与F1、精确度完全对齐，验证了所定义的奖励函数（涵盖命中、遗漏、重新获取、过时）真正捕捉到保留质量。
5. **鲁棒性**：在广泛的成本系数变化下，OSL-MR始终优于所有基线，说明方法对参数选择不敏感。

## 7. 优点：方法或实验设计上的亮点

- **形式化创新**：首次将记忆保留建模为约束随机优化问题，显式考虑长期后果（遗漏、重新获取、过时），为学习提供了清晰的优化基础。
- **严格可观性分离**：引入在线/离线分离，保证学习到的策略在实际部署时不会依赖未来信息，提高了可靠性和现实可行性。
- **冷启动与学习的无缝衔接**：混合评分作为冷启动策略收集数据，训练后平稳过渡到学习策略，无需中断服务。
- **证据学习器设计精巧**：通过预测每个记忆的证据成员关系（可分解、无需枚举所有子集）来近似优化奖励，解决了奖励难以逐项分配的难题。
- **混合先验的双重角色**：既作为强基线，又作为归纳先验提升学习效率，是一种实用且有效的知识注入方式。
- **全面的实验验证**：包括多预算、多数据集、消融、灵敏度分析，实验结果一致且稳健。
