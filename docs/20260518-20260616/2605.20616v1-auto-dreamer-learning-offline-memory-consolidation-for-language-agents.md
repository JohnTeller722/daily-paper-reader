## 摘要
语言智能体越来越多地处理相关任务流，然而现有记忆系统难以将累积的经验转化为可复用的知识。检索增强和结构化记忆方法能够有效记录每轮会话的观察结果，但往往将记忆获取与巩固耦合为一个在线过程，使得智能体缺乏跨会话的全局视角来发现重复模式、抽象共享程序或修剪冗余条目。受互补学习系统理论的启发，我们提出Auto-Dreamer，一种用于语言智能体记忆的离线学习巩固器。Auto-Dreamer将快速的每轮会话记忆获取与缓慢的跨会话记忆巩固解耦。给定一个类型化记忆库的选定工作区域，巩固器将该区域视为只读证据，执行受限的工具使用来检查条目及其来源相关的源轨迹，并综合生成一个紧凑的替换集，该集合跨会话进行抽象并取代原始区域。我们通过GRPO训练Auto-Dreamer，使用端到端智能体性能作为奖励信号，学习如何巩固通过快速在线经验获取的记忆。仅在ScienceWorld轨迹上训练后，Auto-Dreamer在ScienceWorld上相比固定、强化学习训练和提示记忆基线高出7个点，同时使用的活跃记忆库比最强基线小12倍；并且在未重新训练的情况下，在留出的ALFWorld和WebArena上继续保持领先——在ALFWorld上使用的记忆量比最强基线少6倍。

## Abstract
Language agents increasingly operate over streams of related tasks, yet existing memory systems struggle to convert accumulated experience into reusable knowledge. Retrieval-augmented and structured memory methods record per-session observations effectively, but often couple acquisition and consolidation into a single online process, leaving the agent without a global view across sessions to discover recurring patterns, abstract shared procedures, or prune redundant entries. Inspired by complementary learning systems theory, we propose Auto-Dreamer, a learned offline consolidator for language-agent memory. Auto-Dreamer decouples fast per-session memory acquisition from slow cross-session consolidation. Given a selected working region of a typed memory bank, the consolidator treats the region as read-only evidence, performs bounded tool-use to inspect entries and provenance-linked source trajectories, and synthesizes a fresh compact replacement set that abstracts across sessions and supersedes the original region. We train Auto-Dreamer via GRPO, using end-to-end agent performance as the reward signal to learn how to consolidate memories acquired through fast online experience. Trained on ScienceWorld trajectories alone, Auto-Dreamer outperforms fixed, RL-trained, and prompted memory baselines on ScienceWorld by 7 points while using an active memory bank 12$\times$ smaller than the strongest baseline, and continues to lead on held-out ALFWorld and WebArena without retraining -- using 6$\times$ less memory than the strongest baseline on ALFWorld.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：语言智能体在执行连续相关任务时，需要长期记忆来将累积的经验转化为可复用的知识。现有记忆系统（如检索增强记忆、结构化记忆等）能有效记录每轮会话的观察，但它们通常将记忆的**获取（acquisition）**与**巩固（consolidation）**耦合为一个在线的单步更新过程，导致智能体缺乏跨会话的全局视角，无法发现重复模式、抽象共享程序、解决矛盾或修剪冗余条目。
- **背景**：受人类互补学习系统（Complementary Learning Systems, CLS）理论启发，该理论认为海马体快速编码单个情节，而新皮层缓慢提取跨情节的共享结构。Auto-Dreamer将该理论作为操作设计原则，将快速获取与慢速跨会话巩固分离。
- **整体意义**：通过离线学习进行记忆巩固，可以显著提升语言智能体的任务成功率和记忆效率（更小的活跃记忆库），并且学到的巩固策略能跨领域和跨写入器骨干迁移。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **两时间尺度记忆（Two-timescale memory）**：将记忆系统分为快速的逐会话在线获取（由固定提示的写入器完成）和慢速的跨会话离线巩固（由可学习的巩固器完成）。
- **区域重写（Region Rewriting）**：巩固器对选定的工作区域（working region）进行操作，将该区域视为只读证据，利用工具查看条目和溯源轨迹，然后综合生成一个紧凑的替换集，替换原始区域。这种替换语义使得抽象、去重、矛盾解决和遗忘成为默认行为，紧缩性源自操作本身。

### 关键技术细节
1. **记忆结构**：类型化记忆银行包含语义型（事实知识）和程序型（操作技能）条目。每个条目有名称、正文和指向源轨迹的溯源链接。
2. **写入操作（Write Operation）**：定义了区域重写函数：
   - 输入：记忆银行B、工作区域R ⊆ B、与R中条目相关联的源轨迹集合T_R。
   - 输出：替换集S = C_θ(R, T_R)，更新后的银行B* = (B \ R) ∪ S。
   - 写入器是固定、追加式的，不搜索现有银行或跨会话比较。
3. **巩固器（Consolidator）C_θ**：基于Qwen3-14B初始化，执行受限的工具使用展开（tool-use rollout），包括搜索记忆、检查候选条目、获取源轨迹、合成新条目。展开达到预算上限或 emit `terminate` 结束。
4. **训练方法**：使用GRPO（Group Relative Policy Optimization）进行强化学习训练。训练时只更新巩固器参数，其他组件（任务智能体、写入器、检索器、内存模式、令牌预算）固定。
5. **奖励设计**：复合奖励 = 下游性能分数 + α × 反事实效用项。
   - 反事实效用项：对合成替换集进行随机掩码（固定比例ρ的条目），测量掩码前后的性能差异，鼓励保留载荷性记忆、抑制冗余和有害记忆。
6. **训练-部署一致性**：训练时使用局部银行（仅由合成条目组成）进行信用分配，部署时将同一操作应用于完整银行中的工作区域。训练基于离线收集的轨迹池，从中采样支持轨迹构建工作区域。

## 6. 主要结论与发现
1. **Auto-Dreamer提升任务成功并保持紧凑记忆**：在ScienceWorld上达到41.1%成功率（比最强UMEM高7点），同时记忆银行仅6.9k令牌（UMEM为80.9k，ReasoningBank为155.1k）。在ALFWorld和WebArena上也取得最佳或接近最佳成功率，记忆使用远低于最强基线。
2. **学会的巩固器能跨领域和跨骨干迁移**：仅用ScienceWorld轨迹训练，在留出的ALFWorld和WebArena上未经任何更新仍表现领先，包括写入器骨干从Qwen3-14B切换到Gemini-3.1-flash-lite-preview时。
3. **区域重写本身是紧凑性主要机制**：未经RL训练的untrained版本已实现大部分记忆缩减（6-11倍于writer-only），RL训练则提升质量和选择性。
4. **反事实效用奖励抑制冗余**：带rcf训练时记忆大小先增后降，性能与不带rcf相当，而后者记忆持续增长。
5. **多源整合是巩固器常见行为**：溯源扇入（fan-in）分布峰值在5，表明每个合成条目通常综合多个来源条目。
6. **失败模式**：对位置敏感的任务，训练后的巩固器可能过度抽象，丢失局部有用细节（如look_at_obj_in_light任务）。

## 7. 优点（方法或实验设计亮点）
- **两时间尺度设计**：将获取与巩固解耦是新颖且生物学启发的，克服了在线更新缺乏全局视角的问题。
- **区域重写操作**：使紧凑性成为操作本身的内在属性，而非后处理；区域级信用分配使得训练可行。
- **反事实效用奖励**：用一个简洁的随机掩码估计，有效鼓励载荷性记忆、惩罚冗余和有害记忆，且训练时不需额外监督。
- **本地评估信用分配**：训练时使用局部银行（仅合成条目）评价，与部署时的构成行为解耦，但实验表明该局部操作能有效迁移到持久银行。
- **严格公平的实验**：所有方法共享相同的任务智能体、编码器、检索格式和提示框架；仅ScienceWorld用于训练巩固器，其余领域为真正的零样本评估；对比基线全面。
- **丰富的消融和定性分析**：不仅报告指标，还通过案例揭示机制（如LightMem的冗余存储 vs Auto-Dreamer的抽象），以及AWM缺失负面教训的对比。

## 8. 不足与局限
- **评估范围有限**：仅三个基于文本的LLM中介环境，未在结构化状态表示、非文本观察（如视觉）或需编码多模态证据的领域验证。
- **写入器和模式依赖性**：巩固器操作在固定提示写入器和特定语义/程序模式之上，对替代写入器、模式或更嘈杂溯源链接的鲁棒性未测试。写入器遗漏的信息一般无法被巩固器恢复（除非源轨迹中足够突出）。
- **检索预算敏感性**：主实验中检索使用top-K=3和令牌上限，这一设置有利于紧凑银行；其他受益于更大检索预算的方法在此约束下可能被低估。
- **代理训练目标**：局部银行训练是部署时构成的代理，虽然实验表明能迁移，但未刻画局部排名与完整银行排名之间的正式关系。
- **方差报告缺失**：仅报告点估计，未提供种子或任务顺序方差。表1中某些差距（尤其是ALFWorld）较小，方差估计有助于解释显著性。
- **过度抽象风险**：某些任务（如look_at_obj_in_light）中训练后的巩固器可能过度抽象，丢失具体细节，导致性能下降。这是一个已知的失败模式。
- **未讨论记忆写入器训练**：论文将写入器固定，但RL训练写入器（如Mem-α、UMEM）性能有时与Auto-Dreamer差距不大；联合优化获取和巩固可能是未来方向。
