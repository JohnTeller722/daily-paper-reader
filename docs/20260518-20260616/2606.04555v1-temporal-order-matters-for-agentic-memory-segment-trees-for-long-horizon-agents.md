## 摘要
长期对话智能体需要通过与用户不断演进的事件、任务和目标进行交互。此类历史记录本质上是时间性的，然而许多现有记忆系统主要按主题相似性组织信息，可能忽略了事件发生的顺序。我们引入了分段树记忆（Segment Tree Memory，简称SegTreeMem），一种将对话历史表示为按时间顺序排列的语句分段树的记忆架构。SegTreeMem通过在线最右前沿更新规则逐步插入新语句，在形成层次化记忆分段的同时保留时间顺序。在检索时，SegTreeMem通过树传播相关性分数，将局部语义匹配与层次化时间上下文相结合。在三个长期记忆基准测试和两个大语言模型骨干网络上，SegTreeMem相较于平面检索、图结构记忆和树结构记忆基线提升了答案质量。额外的时间顺序排列分析表明，性能提升依赖于在记忆构建过程中保留时间顺序，这支持了时间顺序是智能体记忆关键结构的观点。

## Abstract
Long-horizon conversational agents need to interact with users through evolving events, tasks, and goals. Such histories are naturally temporal, yet many existing memory systems organize information primarily by topical similarity and may ignore the order in which events occur. We introduce Segment Tree Memory, or SegTreeMem, a memory architecture that represents conversation history as a temporally ordered Segment Tree over utterances. SegTreeMem incrementally inserts new utterances through an online rightmost-frontier update rule, preserving chronological order while forming hierarchical memory segments. For retrieval, SegTreeMem propagates relevance scores through the tree to combine local semantic matching with hierarchical temporal context. Across three long-horizon memory benchmarks and two LLM backbones, SegTreeMem improves answer quality over flat retrieval, graph-structured memory, and tree-structured memory baselines. Additional temporal-order permutation analysis shows that the performance gain depends on preserving temporal order during memory construction, supporting the claim that temporal order is a key structure for agentic memory.

## 2. 论文提出的方法论

### 2.1 核心思想
- 将对话历史表示为**时间有序的分段树**：每个节点对应一个连续时间区间的话语子序列，根节点覆盖全部历史，内部节点递归分割为不重叠的子区间，叶子节点为单个话语。
- 树节点携带 **LLM 生成的摘要**作为注释，保留语义和时序信息。

### 2.2 关键技术细节
- **在线构建**（Online Construction）：
  - 每次新话语 `x_t+1` 到达时，只需更新树的**最右前沿（rightmost frontier）**——即所有右端点等于当前时间 t 的节点。
  - 使用**兼容性模型**选择插入点：余弦相似度、pointwise LLM 或 batch LLM。若找到兼容前沿节点，则在其下附加新叶子并更新祖先节点；若无兼容节点，则创建新根和右侧链。
  - 更新范围仅涉及 `O(log|M_t|)` 个节点，满足实时性要求。
- **结构感知检索**（Structure-Aware Retrieval）：
  - 先计算每个节点摘要与查询的局部相关性分数并归一化得到初始分布 `s_q^(0)`。
  - 然后通过**传播矩阵** `W_P` 进行有限步（horizon H）的分数传播，支持**自上而下（top-down）**（分数从父节点向子节点扩散）和**自下而上（bottom-up）**（分数从子节点向父节点聚合）。
  - 最终分数为初始分数与各步传播分数的加权平均（衰减因子 α），据此选出 top-K 节点作为证据。

### 2.3 算法流程（文字说明）
- **构建算法**：Frontier 提取 → 兼容性评分确定插入节点 → 创建新叶子及中间节点 → 更新受影响节点的区间和摘要。
- **检索算法**：逐节点计算局部相关性 → 归一化 → 迭代应用传播矩阵（H 步）→ 加权合并 → 选择 top-K。

## 8. 不足与局限

- **LLM 摘要质量瓶颈**：内部节点摘要可能压缩掉关键细节（如日期、名字），导致检索遗漏。附录 C.4 给出了失败案例。
- **极端情况退化**：如果每个新话语都与当前前沿不兼容，树会退化为高度 O(T) 的级联树，节点数 O(T^2)，丧失效率（附录 C.3.1）。
- **长期话题复发困难**：相同话题被长时间间隔隔开时，在树中距离很远，有限步传播可能无法关联（附录 C.3.2）。
- **传播可能引入噪声**：当附近节点包含语义相关但无关的干扰信息时，传播可能降低精度（附录 C.4 Q5）。
- **仅限文本模态**：未考虑多模态输入、工具调用或动作轨迹。
- **实验覆盖局限**：仅在 3 个英语对话数据集上评估，未验证其他语言或非对话场景（如文档摘要）。
- **未与最先进的 RAG 方法（如 MemWalker、LATTICE）直接对比**，因为其实现不适配在线问答设定（作者说明）。
