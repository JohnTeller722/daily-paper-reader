## 摘要
解决通用任务的机器人需要能够将指令基于其过去的经验，因为人类在给出任务时可能会提及值得注意的过去事件（例如，“带我去昨天发生化学品泄漏的地方”）。由于记忆限制使得存储所有过去事件不可行，长期机器人记忆必须具有选择性，理想情况下只保留那些对未来任务具有高实用性的片段。然而，通用机器人的未来任务通常并非先验给定。为了选择具有普遍实用性的记忆，我们提出将贝叶斯惊讶作为记忆形成的门控机制。我们提出了一种方法，在V-JEPA-2提供的语义丰富且与部署无关的潜在空间中计算惊讶。通过使用我们的门控情景记忆来增强基于4D场景图的空间记忆，我们在机器人问答方面展现了一致的改进，在时间、空间和二元问题上比先前的机器人记忆方法提升了≥12%，并在事件分割任务中以无监督因果方法超越了有监督和非因果方法的性能。

## Abstract
Robots solving generalist tasks need to be able to ground instructions in their past experience, since humans may refer to notable past events when giving a task (e.g., ``Take me to where the chemical spill happened yesterday''). Since memory limits make storing all past events infeasible, long-term robot memory must be selective, ideally retaining only those episodes with high utility for future tasks. However, future tasks are not typically given a priori for generalist robots. To select generically useful memories, we propose Bayesian surprise as a gating mechanism for memory formation. We present an approach to compute surprise in a semantically rich deployment-agnostic latent space provided by V-JEPA-2. Using our gated episodic memory to augment 4D scene graph-based spatial memory, we show a consistent improvement over state-of-the-art benchmarks in robot question answering, outperforming prior robot memory methods by $\geq12\%$ for temporal, spatial, and binary questions, and surpassing the performance of supervised and non-causal methods with an unsupervised causal method in event segmentation tasks.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 使用**V-JEPA-2**编码器将连续帧流映射到高维语义潜在空间，在该空间上维护一个**滑动窗口上的对角高斯模型**作为局部预测分布。
- 对每一新帧，计算**贝叶斯惊讶**——即观测到来前后预测分布之间的KL散度，作为该帧的“惊讶分数”。
- 通过**稳健阈值**（中位数 + γ × 中位数绝对偏差MAD）筛选惊讶分数**局部极大值**，并将对应帧存储为情景记忆（附带短帧窗口、机器人位姿和检索嵌入）。
- 这些情景层叠加到DAAAM的4D场景图空间记忆中，供下游多模态大模型检索回答查询。

### 关键技术细节
1. **特征提取**：使用V-JEPA-2编码器，对长度为M=64的因果滑动窗口（相邻窗口共享M-1帧）输出一个全局特征向量 \(z_t \in \mathbb{R}^{D}\)（D=1024）。
2. **局部预测模型**：在滑动窗口W=64上维护每维的均值 \(\mu_W\) 和标准差 \(\sigma_W\)，构成对角高斯分布 \(p_t = \prod_d \mathcal{N}(\mu_{W,t,d}, \sigma_{W,t,d}^2)\)。
3. **惊讶分数计算**：
   - 采用ℓ₁形式的代理分数（式1）：\(s(t) = \frac{1}{D}\sum_{d=1}^D \frac{|z_t[d] - \mu_{W,t,d}|}{\sigma_{W,t,d}}\)。
   - 推导表明，该分数在O(1/W²)精度下等价于贝叶斯惊讶的KL散度（式2）。
4. **事件触发门控**：
   - 阈值：\(\tau = \text{med}(s) + \gamma \cdot \frac{1}{\Phi^{-1}(0.75)} \cdot \text{MAD}(s)\)，其中\(\gamma=1.0\)，\(\Phi^{-1}(0.75) \approx 0.6745\)。
   - 选择超过该阈值的局部极大值，并执行非极大值抑制去重。
5. **存储与检索**：每个存储事件包含8帧窗口、触发时间、机器人位姿、以及用Perception-Encoder (PE-Core-L14) 编码的文本-图像联合嵌入。下游LLM查询时通过最大嵌入相似度检索相关情景记忆。

1. **惊讶门控显著提升机器人问答性能**：在OC-NaVQA上，相比DAAAM，准确率提升12.0%，位置误差降低12.4%，时间误差降低15.7%；优于均匀和随机情景记忆基线。

3. **记忆效率高**：仅存储约1.7%的帧，即可提供足够的场景信息以回答涉及过去事件的问题。
4. **惊讶信号能捕捉人类常引用的“事件”**：即使数据集的问题并非特意涉及惊讶事件，惊讶门控仍能提供更相关的视觉细节。

## 7. 优点

- **认知科学启发的设计**：将人类记忆形成的预测误差机制引入机器人，具有理论依据。
