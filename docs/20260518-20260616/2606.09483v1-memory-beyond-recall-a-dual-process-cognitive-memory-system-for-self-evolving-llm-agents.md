## 摘要
对于大语言模型代理而言，长期记忆不仅仅是适时检索正确段落。当前的记忆系统将信念修正、因果耦合和跨领域抽象压缩到单一的检索层面以适配表面回忆，因此在需要推理用户如何演化的隐式个性化任务上表现不佳。我们提出DCPM，它沿着认知能力层级重新组织代理记忆，从原始输入和原子事实，经由历时信念轨迹和身份，上升到领域模式、潜在意图和跨领域模式。该层级由两个过程驱动，继承了双过程理论的结构划分：同步的日间写入器（系统1）记录信念修正作为双向链式替换序列，以及异步的夜间引擎（系统2）归纳模式和意图，并扫描跨领域冲突，将其抽象为更高级的核心模式。在LongMemEval、PersonaMem和PersonaMem-v2上，启用系统2在基准测试奖励隐式跨会话推理的任务中贡献最大（PersonaMem-v2上提升高达+5.20），而在跨度回忆上贡献最小，符合架构预测。

## Abstract
Long-term memory for an LLM agent is more than retrieving the right passage at the right time. Current memory systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall, and consequently struggle on implicit personalisation that requires reasoning over how a user has evolved. We propose DCPM, which reorganises agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and identity, to domain schemas, latent intentions and cross-domain patterns. The hierarchy is driven by two processes inheriting the architectural split of dual-process theory: a synchronous daytime writer (System1) that records belief revisions as doubly linked supersedes chains, and an asynchronous nighttime engine (System2) that induces schemas and intentions and sweeps for cross-domain collisions abstracted into higher-level core schemas. On LongMemEval, PersonaMem and PersonaMem-v2, enabling System2 contributes most where the benchmark rewards implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall, matching the architectural prediction.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：当前LLM智能体的长期记忆系统被简化为一个检索问题（向量存储、时间知识图谱、原地更新），它们仅能支持表面事实的回忆，无法处理更高级的认知需求：
  - 追踪用户信念的**修正轨迹**（belief revision）：偏好如何演变、被什么事件触发。
  - 捕捉**因果耦合**（causal coupling）：读取时，两个主题上不相关的信念之间如何通过因果链关联。
  - 实现**跨域抽象**（cross-domain abstraction）：将不同生活领域中的行为模式归纳为统一的认知规则。
- **后果**：智能体在与用户长期对话后，仍然在简单的个性化问询上犯错（如用户明确改变过喜好，但系统只记得最新状态，丢失中间过程）。
- **根本原因**：现有系统将“记忆即存储”与“记忆即认知”混为一谈，缺乏对认知层级结构的建模。
- **论文目标**：基于双过程认知理论（Kahneman 2011）和心理理论（Theory-of-Mind），提出一个面向自演化LLM智能体的认知记忆系统DCPM，将记忆组织为从原始输入到跨域核心模式的认知能力层级。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **认知能力层级**（从低到高）：
  1. 原始输入（raw inputs）和原子事实（atomic facts）
  2. 身份项（identity items）和历时替换链（supersedes chains）
  3. 域内模式（within-domain schemas）和潜在意图（latent intentions）
  4. 跨域核心模式（cross-domain core schemas）
- **双过程架构**：继承认知双过程理论的架构分离（非时间分离）：
  - **系统1（System 1）**：同步的日间写入器，在线处理每条`add_memory`请求，记录事实和身份项，并通过双向指针（SUPERSEDES/SUPERSEDED BY）构建替换链。
  - **系统2（System 2）**：异步的夜间引擎，离线运行（空闲或夜间窗口），对积累的事实进行聚类、归纳域内模式和意图、并通过双空间碰撞检测抽象出跨域核心模式。

### 2.2 关键技术细节

**系统1（日间写入器）**：
- 触发条件：仅在用户或应用显式调用`add_memory`时执行（非每轮对话）。
- 四步流程：
  1. **原始持久化**：将原始输入无损失写入向量存储。
  2. **提取**：使用提取LLM Me从当前轮次+最近上下文窗口中提取出身份项和原子事实（含类型、主题、显著性、时间戳）。
  3. **调和**：使用调和LLM Mr对每个提取项与向量存储中的top-k近邻进行比较，决定三种操作之一：
     - `ADD`：全新无重叠
     - `SUPERSEDE`：矛盾或进化版本
     - `UPDATE`：补充或扩展
     - 精确重复则丢弃。
  4. **批量插入与替换链**：对涉及`SUPERSEDE`的项，写入双向指针：新项`SUPERSEDES`旧项，旧项`SUPERSEDED BY`新项。旧项不删除，形成双向链表。

**系统2（夜间引擎）**：
- 三个阶段：
  1. **预处理（无LLM）**：对尚未被任何模式/意图节点引用的新事实进行两阶段DBSCAN聚类。第一阶段ε=0.35，第二阶段ε=0.25细划分。计算每个聚类的质心嵌入，并检索图中最近的现有节点。
  2. **LLM-agent归纳**：对每个聚类，调用归纳代理Ma（配备四个工具：CREATE_SCHEMA、CREATE_INTENTION、ADD_EVIDENCE、ADD_EDGE），生成域内行为模式节点和潜在意图节点，并写证据边`evidence_vdb_ref`。
  3. **跨域扫描器**：
     - 行为抽象：对每个模式节点，用LLM生成简短的行为描述（如“沉没成本后升级承诺”），并用句子编码器得到行为-认知嵌入`E_beh`和语义嵌入`E_sem`。
     - 碰撞扫描：对跨域模式对，满足以下条件时标记为“碰撞”：
       - 行为相似度 \( \cos(E_{beh}(s_i), E_{beh}(s_j)) > \theta_{beh} \)
       - 语义相似度 \( \cos(E_{sem}(s_i), E_{sem}(s_j)) < \theta_{sem} \)
       - 阈值：\( \theta_{beh}=0.72, \theta_{sem}=0.40 \)（基于PersonaMem-v2训练集调整）。
     - 核心归纳：对每个碰撞簇，用LLM Mc生成更高级的跨域核心模式，写入图G并连接所有成员模式。

**读取路径**：
- 推理时，查询嵌入通过向量相似度命中事实/身份存储，遍历替换链，再通过证据边找到图G中的模式/意图/核心模式节点。**整个过程无LLM调用**，延迟主要由向量搜索主导。

**复杂度**：
- 写入：O(N log N) + LLM调用次数（每个turn一次提取+一次调和）。
- 系统2：预处理O(N)无LLM，归纳阶段O(|C|) LLM调用，扫描阶段O(D·s̄)行为抽象LLM + O((D·s̄)²)向量比较 + 每个碰撞簇一次核心归纳LLM。实践中D≤20, s̄≤30。
- 读取：O(log N + k̄)（一次ANN + 链遍历），无LLM。

## 6. 主要结论与发现

1. **双过程架构的预测得到验证**：启用系统2在隐式跨域推理任务（PersonaMem-v2）上提升最大（+2.51/+5.20），而在表面回忆任务（LongMemEval, PersonaMem）上提升很小（+0.44~+2.41）。这与理论预测一致——系统2提供的是认知抽象而非更多表面内容。

2. **替换链是关键机制之一**：消融实验中，去除系统2+替换链造成8.10点下降，其中替换链单独贡献约2.9点。在LongMemEval知识更新子集中，78%正确回答的查询触及了替换指针，而错误回答只有31%。

3. **跨域核心模式是最高杠杆组件**：仅占节点1.3%的跨域核心模式贡献了约4.1个点（Figure 3），说明其编码了高信息密度的认知结构。

4. **结构化记忆可超越长上下文模型**：在LongMemEval（kimi）上，DCPM full达到86.14%，比长上下文基线高5.53点，主要原因是避免了“丢失在中间”效应。

5. **系统2除跨域碰撞外，模式和意图也有贡献**：去掉模式/意图再降1.1点，表明域内抽象也有价值。

6. **当前记忆系统的瓶颈**：Figure 5显示，表面回忆类（知识更新、用户事实）已接近饱和（90%+），而集成推理类（偏好、多会话、时间推理）仍较低（40-70%），这正是DCPM试图攻克的领域。

## 7. 优点

- **理论驱动设计**：认知能力层级和双过程分离有认知科学（Theory-of-Mind, dual-process theory）基础，非工程凑合。
- **读取路径无LLM**：推理时只有向量搜索+指针遍历，延迟低且可控，适合生产部署。
- **不需要每轮写入**：系统1仅在显式请求时触发，节省成本。
- **历时连续性**：通过替换链保留信念演化全过程，允许复杂因果检索。
- **跨域抽象能力**：双空间碰撞检测能识别语义不同但行为相似的模式，生成核心模式，这是现有系统无法做到的。
- **实验有针对性**：三个基准恰好对应论文指出的三个缺失能力，消融实验因果清晰。
- **定性案例生动**：如健身信念五阶段变化、园艺与教学核心模式，展示了抽象能力。

## 8. 不足与局限

- **评估范围窄**：仅英文聊天助手场景，未研究跨语言、具身代理、多用户互动或身份不确定的场景。

- **阈值手动调优**：DBSCAN的ε值、碰撞阈值θ_beh和θ_sem均在PersonaMem-v2的held-out split上调优，可能在其他数据集上不稳定。论文也提到θ_beh对基准敏感。
- **自然语言节点**：模式、意图、核心模式用自然语言存储，虽可解释但不可代数运算（如不能做集合交并），且继承提取LLM的冗长和不一致性。

- **隐私风险**：跨域核心模式可能推断用户未明确关联的行为模式，论文虽在伦理声明中提出建议（默认禁用、用户审查、硬删除），但未在实验中体现。
