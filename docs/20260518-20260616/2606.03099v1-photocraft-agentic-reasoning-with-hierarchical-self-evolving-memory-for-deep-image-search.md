## 摘要
深度图像检索需要基于丰富的上下文线索（如时间、地点和事件关系）进行多步推理。然而，现有的大多数基于LLM的代理是无状态和反应式的，缺乏持久记忆来维持长期上下文或在任务间迁移经验，这常常导致执行漂移和经验隔离。为解决这些局限，我们提出PhotoCraft，一种无需训练的、用于照片搜索代理的层次化记忆系统。受人类认知启发，PhotoCraft为多模态大语言模型配备工作记忆、情景记忆和语义记忆，在推理过程中动态调用这些记忆，以在整个多步推理和答案生成中保持逻辑一致性和知识可迁移性。在DISBench上的大量实验表明，PhotoCraft在不同多模态大语言模型骨干上持续提升了上下文感知检索能力，最高可获得18.5%的提升，有效缓解了无记忆深度图像检索中的关键瓶颈，为构建可靠且可泛化的多模态搜索代理提供了一条实用路径。

## Abstract
Deep Image Search requires multi-step reasoning over rich contextual cues, such as time, location, and event relations. However, most existing LLM-based agents are stateless and reactive, lacking persistent memory to maintain long-horizon context or transfer experience across tasks, which often leads to execution drift and experience isolation. To address these limitations, we propose PhotoCraft, a training-free, hierarchical memory system for photo-search agents. Inspired by human cognition, PhotoCraft equips MLLMs with working, episodic, and semantic memory, which are dynamically invoked during reasoning to preserve logical consistency and knowledge transferability throughout multi-step reasoning and answer generation. Extensive experiments on DISBench demonstrate that PhotoCraft consistently improves context-aware retrieval across diverse MLLM backbones, achieving gains of up to 18.5\% and effectively mitigating key bottlenecks in memoryless deep image search, offering a practical path toward reliable and generalizable multimodal search agents.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 构建一个三流记忆系统，使MLLM代理在推理过程中动态维护和利用短期情境、历史经验与抽象策略。
- 代理以ReAct风格的循环方式自主调用多模态工具（如视觉检索、元数据查询、照片查看、网络搜索），同时持续更新记忆。

### 关键技术细节
1. **工作记忆（Working Memory）**  
   - 保留短时推理状态：包含步骤级动作与结果摘要（S_digest）、会话级关键决策（S_session）、当前子目标与下一步计划（S_working）。  
   - 当上下文接近窗口限制时触发压缩，并引入**保真度验证器**（Fidelity Validator），检查元数据（如照片ID、时间约束）是否丢失，若丢失率L > 0.5则保留原始关键消息。

2. **情景记忆（Episodic Memory）**  
   - 在代理生成候选答案后，执行**事后反射审计**（Post-hoc Verification），从五个维度（ANCHOR、CONSTRAINT、TARGET、COMPLETENESS、DECISION）检查推理链一致性。  
   - 若发现不一致，将审计结论追加至工作记忆，并触发新一轮检索（使用差异化关键词），实现反思式自我纠正。

3. **语义记忆（Semantic Memory）**  
   - **技能蒸馏**：在每次成功完成（F1≥0.85）的轨迹上，利用蒸馏模块提取结构化技能条目（含任务模式、策略、关键洞察、适用条件等），并去实体化以保留抽象模式。  
   - **技能整合**：使用句子编码器（sentence-transformer）对源查询编码，余弦相似度>0.8时合并技能，避免冗余。  
   - **技能检索与注入**：对新查询计算与已有技能源查询的相似度，超过阈值θ_retr=0.65时将其提示前置到用户消息中，由代理自主决定是否采纳。

- 工作记忆压缩：S = f_mem(Hc, Q) = S_digest ⊕ S_session ⊕ S_working。保真度验证：若元数据丢失率L > τ（τ=0.5），保留原始关键消息；否则执行标准压缩。
- 情景记忆审计信号：E = f_epi(Q, Hc, V(ˆR))，输出五个维度的检查结果。
- 语义记忆技能合并条件：cos(ϕ(q_new), ϕ(q_j)) > 0.8，则合并；否则独立入库。
- 整体推理循环：控制器→选择工具→观察结果→写入工作记忆→累积情景记忆→审计→必要时重检索→任务结束后蒸馏技能。

## 6. 主要结论与发现

1. **PhotoCraft在所有评估模型上一致提升性能**：最高提升18.5%（如Qwen3-VL-32B-Instruct在Inter-Event上EM+18.4%，F1+18.5%）。  
2. **记忆组件缺一不可**：移除任何记忆模块均导致性能显著下降，表明三者的互补整合至关重要。  
3. **工作记忆的保真度验证器有效**：无约束压缩导致61%失败率，保真验证补偿关键元数据。  
4. **情景记忆通过反思式审计减少执行漂移**：错误分析显示推理中断错误从31降为20。  
5. **语义记忆从成功轨迹中蒸馏技能有效**：从失败轨迹蒸馏反而降低性能（因失败原因异质）。  
6. **直接检索在DISBench上极低**（Recall@3仅10-12.5%），证明检索范式瓶颈在于上下文推理而非模型容量。  
7. **跨模型泛化性好**：即使在弱嵌入模型（2B）下也有显著增益，说明主要瓶颈是推理而非检索质量。
