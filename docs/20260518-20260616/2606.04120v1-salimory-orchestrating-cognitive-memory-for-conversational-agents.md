## 摘要
作为终身伴侣的对话代理必须在所有交互中保持持久记忆。然而，简单地用原始检索扩展上下文窗口会降低推理质量，而通过标准强化学习训练记忆代理会在多阶段流程中造成严重的信用分配瓶颈。为解决这一问题，我们引入SALIMORY，一个训练单一语言模型来管理认知结构化的记忆跨度（用户事实、偏好和工作记忆）的框架。通过引入分层阶段过程奖励和奖励分解的对比细化，SALIMORY为不同的记忆操作（选择性过滤、巩固和线索驱动回忆）提供了端到端的独立监督。SALIMORY将记忆归因的失败减少了三分之一，在端到端准确率上比现有最佳方法高出10%以上，并且良好的个性化率提高了一倍以上。

## Abstract
Conversational agents that serve as lifelong companions must maintain persistent memory across all interactions. However, simply expanding context windows with raw retrieval degrades reasoning quality, while training memory agents via standard reinforcement learning creates a severe credit assignment bottleneck in a multi-stage pipeline. To solve this, we introduce SALIMORY, a framework that trains a single language model to manage a cognitively-structured memory-spanning user facts, preferences, and working memory. By introducing a hierarchical stage-wise process reward and reward-decomposed contrastive refinement, SALIMORY provides isolated supervision for distinct memory operations (selective filtering, consolidation, and cue-driven recall) end-to-end. SALIMORY cuts memory-attributed failures by one-third, outperforms the state-of-the-art by over 10% in end-to-end accuracy, and more than doubles the Good Personalization rate.

**核心问题**

- 强化学习训练多阶段记忆管道时，最终答案奖励过于稀疏，导致严重的**信用分配瓶颈**（难以区分失败源于记忆形成、巩固还是利用）。  

**整体含义**  
- 提出一个受认知科学启发的架构 + 角色分解的RL训练框架，实现记忆管理全流程的端到端优化，显著提升持久对话的准确性和个性化质量。

## 2. 论文提出的方法论

### 2.1 认知启发的记忆架构

- **三个互补的记忆库**：  
  - **事实库（Factual Bank, F̅）**：用户可验证的事实（如乳糖不耐受）。  
  - **偏好库（Preference Bank, P̅）**：主观喜好（如偏爱燕麦奶）。  
  - **工作记忆（Working Memory, W̅）**：近期显著的对话回合（用户可能仍记得）。  
- 分离长期轮廓与短期上下文、客观事实与主观偏好，实现更精准的个性化。

### 2.2 单一策略模型 πθ 的三重角色

通过不同的指令提示，一个9B大小的语言模型扮演三个角色：  
- **Saliency Filter（选择性注意力）**：判断哪些回合值得记录。  
- **Memory Booster（巩固器）**：更新三个记忆库，淘汰过时条目。  
- **Memory Utilizer（线索驱动利用）**：在查询时合成相关记忆生成适配的用户轮廓 Mq。  

### 2.3 阶段过程奖励系统（Stage-Wise Process Reward）

为解决信用分配，设计三层奖励，针对不同角色提供独立监督：

- **R1（响应质量）**：基于正确答案α和个性化质量p，使用**乘法门控**：R1 = α·(1+λp·p)（若适用个性化），否则R1 = α。确保只有在答案正确时奖励个性化。  
- **R2（记忆质量）**：评估记忆库的事实性ϕ_f和模糊性ϕ_v，γ=ϕ_f·(1-ϕ_v)。采用**不对称惩罚**：R2 = -λ_pen·(1-γ) + λ_bon·γ，λ_pen=3×λ_bon。迫使模型宁可省略也不编码模糊记忆。  
- **R3（利用与过滤质量）**：  
  - μ：利用得分（合成轮廓与问题的相关度）；  
  - κ：过滤准确性（召回加权混合，更重视避免遗漏）。  
- **总奖励** L_GRPO = R1 + R2 + R3，每个奖励定向影响对应角色。

### 2.4 奖励分解对比精炼（Reward-Decomposed Contrastive Refinement）

- 在GRPO批次内，构建**角色特定的偏好对**：  
  - **Booster对比**：基于R2分数选择胜负对，梯度大小由差距ΔR2缩放。  
  - **Utilizer对比**：基于利用得分μ选择，但加入**因果门控**：仅当两个rollout的记忆库Jaccard相似度>τ_sim时才形成对比对，排除上游记忆质量差异的混淆。  
- 总对比损失 L_Cont = λ_b·L_boost_cont + λ_u·L_util_cont，与主GRPO目标相加。

### 2.5 整体优化

最终损失函数：L_total = (1/N) Σ L_GRPO(ξ) + L_Cont。  
- GRPO提供基线更新并训练过滤角色，L_Cont选择性路由梯度只更新巩固器和利用器。
