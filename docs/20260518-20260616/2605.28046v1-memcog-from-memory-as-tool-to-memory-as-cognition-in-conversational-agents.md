## 摘要
现有代理记忆系统普遍遵循我们称之为“记忆即工具”的范式，其中单个查询触发对平坦段落列表的一次性检索，存在被动调用、推理与检索解耦以及检索片段与代理导航需求之间的结构不匹配等问题。我们提出MemCog，一种“记忆即认知”系统，将记忆访问作为推理过程的内在组成部分。MemCog通过关联链接图将用户知识组织为可导航记忆存储，提供跨维度导航接口以支持多步推理驱动的遍历，并采用主动推理协议，驱动代理自发地从对话上下文中启动记忆探索。此外，我们构建了ProactiveMemBench，这是首个用于评估主动记忆触发的基准。实验表明，MemCog在被动QA基准（LoCoMo上92.98，LongMemEval上95.8）上达到最先进水平，同时在ProactiveMemBench上显著优于基线，展示了“记忆即认知”的优势。

## Abstract
Existing agent memory systems universally follow what we term a Memory-as-Tool paradigm where a single query triggers one-shot retrieval of flat passage lists, suffering from passive invocation, reasoning-retrieval decoupling, and structural mismatch between retrieved fragments and the agent's navigational needs. We propose MemCog, a Memory-as-Cognition system that makes memory access an integral part of the reasoning process. MemCog organizes user knowledge as Navigable Memory Store with associative link graphs, exposes Cross-Dimensional Navigation Interface for multi-step reasoning-driven traversal, and employs Proactive Reasoning Protocol that drives agents to spontaneously initiate memory exploration from conversational context. We additionally construct ProactiveMemBench, the first benchmark for evaluating proactive memory triggering. Experiments show that MemCog achieves state-of-the-art on passive QA benchmarks (92.98 on LoCoMo, 95.8 on LongMemEval) while substantially outperforming baselines on ProactiveMemBench, demonstrating the advantage of Memory-as-Cognition.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有范式局限**：当前对话智能体的记忆系统普遍遵循“记忆即工具”（Memory-as-Tool）范式——一次查询触发一次检索，返回平坦段落列表。该范式存在三个根本性缺陷：
  - **调用瓶颈**：记忆系统仅在智能体明确发出工具调用时才被动激活，无法主动根据对话上下文自发触发记忆探索。
  - **推理‑检索解耦**：检索是孤立的一次性过程，智能体的推理能力无法干预检索流程，导致响应质量受限且两个模块独立优化。
  - **结构不匹配**：即使记忆以层次化方式组织，返回的 top‑k 片段也缺乏结构化的导航信息，智能体无法推断后续最佳检索路径。
- **研究目标**：提出一种新范式“记忆即认知”（Memory-as-Cognition），将记忆访问从预处理步骤转变为智能体推理过程的核心组成部分，同时弥补已有基准仅评估被动问答的缺口。

## 2. 方法论：核心思想、关键技术细节

MemCog 由三个紧密协同的组件构成：

### 2.1 可导航记忆存储（Navigable Memory Store）
- **层次化组织**：将用户知识组织为三个粒度层级：
  - **维度（Dimension）**：顶层类别（如个人偏好、工作、社交关系、重要事件）。
  - **页面（Page）**：每个维度内的独立知识单元，覆盖连贯主题。
  - **部分（Section）**：页面内的细粒度信息块，包含标题、摘要、结构化事实、相关页面、时间上下文、置信度分数。
- **跨维度关联链接**：定义四种链接类型（related_to、temporal_next、caused_by、contrasts_with），构成叠加图，支持跨维度遍历。
- **构建与演化**：初始时从对话历史中提取事实并聚类为页面和链接；每次对话后通过增量更新（匹配、修改、新建、矛盾检测）使记忆库持续进化。

### 2.2 跨维度导航接口（Cross-Dimensional Navigation Interface）
- 替代单次搜索工具，提供多种粒度导航动作：
  - `list_dimensions()`：返回所有维度概览。
  - `browse_dimension(dim)`：返回指定维度下的页面标题和摘要。
  - `read_page(page_id)`：返回页面完整内容及所有出站链接。
  - `follow_link(link)`：沿超链接跳转到目标页面。
- 每个动作不仅返回请求内容，还包含结构上下文（可用链接、同级页面、维度位置），以支持智能体的后续导航决策。

### 2.3 主动推理协议（Proactive Reasoning Protocol）
- **两种模式**：
  - **主动关联**：当对话上下文暗示与存储知识有潜在连接时（如提及人物、地点、话题；对话可从历史背景获益；用户陈述与存储信息矛盾），智能体自发启动记忆导航。
  - **被动响应**：用户明确询问过去信息时，智能体进行导航。
- **选择性表面化**：在输出前，智能体评估回忆信息的四维属性（与当前上下文的相关性、时间有效性、敏感性、冗余性），由其自身推理在 Think 阶段完成。
- **协议实现**：通过结构化系统提示（system prompt）定义行为规范，与 ReAct 循环结合，实现推理与检索的紧密耦合。

## 3. 实验设计

### 3.1 使用的数据集/基准

## 6. 主要结论与发现

- MemCog 在被动 QA 基准上达到 SOTA：LoCoMo 上 92.98（GPT‑4.1‑mini），LongMemEval 上 95.8。
- 在主动记忆触发基准 ProactiveMemBench 上，MemCog 的 Recall@5 为 59.51，LLM‑judged Precision 87.58，Human‑judged Precision 91.02，显著优于所有 Memory‑as‑Tool 基线。
- 消融实验表明：
  - 主动协议对被动 QA 影响小（‑0.35），但对主动触发性能破坏极大（Recall@5 ‑14.63），说明其专门解决调用瓶颈。
  - 关联链接图和层次结构对两种任务都重要，移除后性能下降明显。
  - 组件之间存在互补协同：协议提供认知驱动力，结构提供持续导航的线索，二者结合产生最大收益。
- 记忆访问范式应被视为一个光谱（无记忆 → 单次搜索 → 多步导航 → 自发回忆），MemCog 实现了向更认知化方向的重要推进。

## 7. 优点

- **范式创新**：首次提出“记忆即认知”概念，将记忆访问与推理过程深度融合，替代了传统的“检索‑然后‑推理”分离模式。
- **协议‑结构协同**：主动推理协议与可导航记忆存储相互增强，消融实验清晰验证了这种互补关系。
- **构建了主动记忆基准**：填补了评估主动触发能力的空白，为后续研究提供了标准化测试平台。
- **全面的实验验证**：在三个维度（被动 QA、长程记忆、主动触发）上进行评估，基线广泛，消融完整，并提供了详细的案例分析。
- **可扩展性分析**：讨论了页面增长呈亚线性、导航令牌开销可控、增量更新成本低等实际部署特征。

## 8. 不足与局限

- **额外令牌开销**：多步导航的平均 2–3 步调用在严格延迟或成本约束下可能显著，尤其对于简单查询，可能过度消耗资源。
- **依赖骨干模型指令遵循能力**：主动推理协议要求弱模型可能表现不佳（论文提到更弱模型性能方差更大）。
- **受限于页面构建质量**：如果事实提取或链接建立存在错误，整个系统的导航质量会下降。
- **早期对话阶段劣势**：在对话历史稀疏时，记忆图连接不足，导航优势有限。
- **实验覆盖面**：ProactiveMemBench 仅使用 GLM‑5.1 作为骨干进行完整评估，未展示 GPT‑4o‑mini 或 GPT‑4.1‑mini 的结果，可能未能完全排除骨干模型差异对结论的影响。
- **未探讨实际部署中的成本与延迟**：虽然分析了 token 和复杂度，但没有进行真实 API 成本或端到端延迟的实验对比。
