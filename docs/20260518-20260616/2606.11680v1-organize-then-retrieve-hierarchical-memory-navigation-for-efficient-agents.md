## 摘要
大语言模型（LLM）智能体由于本质上的无状态性，在处理长 horizon 任务时面临困难，需要将所有任务相关信息编码到不断增长的输入上下文中。由此导致的推理质量下降、推理成本增加和延迟升高，促使了高效工作记忆机制的必要性。然而，现有方法要么依赖有损压缩，要么基于相似性检索，这些方法往往无法捕捉多步骤智能体任务所需的时间结构和因果依赖。在这项工作中，我们提出了 HORMA，一种层次化组织与检索记忆智能体，它将经验组织成类文件系统的层次结构，其中摘要实体与对应的原始轨迹相链接，从而实现高效访问而不丢失详细信息。HORMA 将工作记忆分解为两个阶段：结构化记忆构建和基于导航的检索。构建模块通过区分由信息缺失导致的失败和由误导性或过载上下文导致的失败，迭代地优化经验的结构化方式。导航模块通过使用轻量级智能体遍历层次结构来检索任务相关上下文，该智能体通过强化学习训练，以选择最小但足够的上下文，从而减少关键执行路径上的延迟。在 ALFWorld、LoCoMo 和 LongMemEval 上，HORMA 在受限上下文预算下提高了任务性能，同时在长对话任务中最多仅使用基线 token 用量的 22.17%。与现有方法相比，它持续实现了更好的效率-性能权衡，并有效泛化到未见过的任务。

## Abstract
Large language model (LLM) agents struggle with long-horizon tasks due to their inherent statelessness, requiring all task-relevant information to be encoded in growing input contexts. The resulting degraded reasoning quality, increased inference cost, and higher latency necessitate efficient working memory mechanisms. However, existing approaches either rely on lossy compression or similarity-based retrieval, which often fail to capture temporal structure and causal dependencies required for multi-step agentic tasks. In this work, we present HORMA, a Hierarchical Organize-and-Retrieve Memory Agent that organizes experience into a file-system-like hierarchical structure, where summarized entities are linked to the corresponding raw trajectories, enabling efficient access without losing detailed information. HORMA decomposes working memory into two stages: structured memory construction and navigation-based retrieval. The construction module iteratively refines how experiences are structured by distinguishing between failures caused by missing information and those caused by misleading or overloaded context. The navigation module retrieves task-relevant context by traversing the hierarchy using a lightweight agent trained with reinforcement learning to select minimal yet sufficient context, thereby reducing latency along the critical execution path. Across ALFWorld, LoCoMo, and LongMemEval, HORMA improves task performance under constrained context budgets while requiring at most 22.17% of the baseline token usage in long conversation tasks. Compared to existing methods, it consistently achieves better efficiency-performance trade-offs and generalizes effectively to unseen tasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）智能体在处理长时程任务（long-horizon tasks）时，因其无状态性（statelessness）而将所有任务相关信息不断累积到输入上下文中，导致上下文过长、推理质量下降、推理成本增加和延迟升高。
- **现有方法的局限**：
  - 直接保留全部历史（history hoarding）导致上下文过载、信息稀释、高延迟和成本。
  - 有损压缩（如摘要、上下文折叠）会不可逆地丢失细粒度信息，影响下游推理。
  - 基于相似性检索的外部记忆将经验组织为平面集合，无法捕捉时间层次和因果依赖，检索退化为浅层语义匹配，返回时间不一致或无关信息。
- **研究目标**：构建一种高效、结构化的工作记忆机制，既能选择性保留任务相关信息，又能以可导航的层次结构组织经验，提升下游任务性能。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 提出 **HORMA**（Hierarchical Organize-and-Retrieve Memory Agent），将工作记忆解耦为两个专门模块：
  1. **记忆管理器（Memory Manager）**：负责结构化记忆构建，将原始轨迹组织成类文件系统的层次结构，链接摘要实体与原始轨迹。
  2. **检索智能体（Retrieval Agent）**：负责基于导航的检索，通过强化学习训练，在层次结构中遍历以选择最小但充分的上下文。

### 关键技术细节
1. **层次化记忆工作空间**：
   - 使用文件系统式结构（目录和文件）存储经验，每个合成笔记包含任务相关抽象、时间元数据、指向原始轨迹的引用。
   - 支持通过 Bash 工具（如 `ls`, `cd`, `grep`, `cat`）进行可解释的交互操作。

2. **记忆管理器：技能演化式构建**：
   - 初始化时使用具有强层次推理能力的 LLM（如 Claude Sonnet 4.5）的领域无关提示。
   - 通过对比分析成功与失败轨迹，递归精化管理策略：
     - **外生失败**（Exogenous）：全历史成功但HORMA失败 → 信息丢失 → 需补充缺失信息。
     - **内生失败**（Endogenous）：HORMA成功但全历史失败 → 结构化记忆缓解了幻觉/中间丢失问题 → 需强化该技能。
   - 生成反馈和新的记忆管理技能，累积成技能库（skill library）。

3. **检索智能体：基于强化学习的优化**：
   - 将检索建模为基于文件系统操作的决策过程，使用 Bash 工具。
   - 新增两个终端动作：`select`（确认内容加入上下文）和 `done`（终止检索）。
   - 使用 **GRPO**（Group Relative Policy Optimization）优化策略。
   - 定义基于证据的重叠奖励函数：\( J(C_t, E) = \frac{|C_t \cap E|}{|C_t \cup E|} \)，鼓励精确且简洁的上下文选择。
   - 轻量级检索骨干（如 Qwen 3.5 4B）可单独训练，提升效率。

4. **记忆增强智能体策略**：
   - 主智能体 \(M_\theta\) 的决策依赖检索到的上下文 \(C_t\) 而非全部历史：\(\pi(a_t | o_t, F_t, q) = M_r(C_t | F_t, q) \cdot M_\theta(a_t | o_t, C_t, q; P_{\text{main}})\)。
   - 记忆状态 \(F_t\) 作为外部持久化工作空间，随时间演化。

## 3. 实验设计

### 使用的数据集/场景
- **ALFWorld**：基于文本的家居交互环境（134个任务，6类），评估长时程规划与执行。
- **LoCoMo**：长对话基准（10个对话），评估单跳、时间、对抗性问答（测试集519个实例）。
- **LongMemEval**：多会话对话记忆基准（367个实例），涵盖知识更新、单会话、时间推理等任务。

### Benchmark 设置
- 上下文预算：ALFWorld 设定小（1950 tokens）和大（2200 tokens）两个限制；LoCoMo 限制 10K tokens；LongMemEval 限制 50K tokens。
- 主骨干模型统一使用 **Claude Sonnet 4.5** 进行公平比较。
- 检索智能体训练：仅使用 LoCoMo 前7个对话（1089个QA实例）训练轻量级 Qwen 3.5 4B 检索器，在其他基准上零样本测试。

### 对比方法
- **内部静态记忆**：Truncation, Slide Window, Embedding
- **内部动态记忆**：ReSum, Acon, Fold, HIAGENT
- **外部动态记忆**：A-MEM, Mem0, Embedding Retrieval（基于HORMA的结构化笔记）
- **无限制参考**：No limit（全历史输入）

### 评估指标
- ALFWorld：成功率、平均交互步数、每步平均 token 数
- 对话基准：L-J 分数（LLM-as-judge，Claude Sonnet 4.5 评判）、F1 分数、总输入 token 数

## 7. 优点

1. **解耦设计**：将记忆构建和检索分离，优化各自的目标：
   - 记忆构建利用LLM已有能力（层次推理），避免不稳定的端到端RL。
   - 检索直接优化执行路径，减小信用分配差距。
2. **层次化文件系统工作空间**：
   - 支持可解释的、基于导航的访问，保留时间结构和因果关系。
   - 通过 Bash 工具操作，易于集成和扩展。
3. **强化学习优化检索策略**：
   - 使用 GRPO 训练轻量级检索器，降低推理成本，提升检索精度。
   - 证据重叠奖励提供细粒度反馈，与下游推理分离。
4. **跨域泛化**：训练于对话数据可在不同交互任务中有效迁移。
5. **系统性消融与错误分析**：清晰揭示了各模块贡献及失败模式。

## 8. 不足与局限

1. **记忆管理器的容量要求高**：
   - 弱管理器（如 Qwen 3.5 4B）无法有效组织信息，即使搭配强检索器也无济于事。这限制了该方法在资源受限场景下的应用。
2. **RL 训练范围有限**：
   - 检索智能体仅在 LoCoMo 训练集上训练，虽展现了泛化，但未在更多样化的任务上验证在线持续学习能力。
3. **记忆构建基于离线对比分析**：
   - 技能演化依赖于对成功/失败轨迹的后验对比，而非实时交互反馈。可能无法充分捕捉动态环境的突变。
4. **实验覆盖的局限性**：
   - 仅涵盖三个基准，主要面向语言交互和对话。未在更复杂的具身环境（如具身导航、机器人控制）或更真实的动态任务中评估。

   - 对话基准主要依赖 LLM-as-judge 评分，可能引入偏好偏差。虽补充了 F1 分数，但 F1 分数整体较低（附录表6），且部分任务类型上 HORMA 的 F1 优势不如 L-J 明显，说明自动评估与人工一致性存在差距。
6. **上下文预算设定基于经验**：
   - 预算值虽基于无限制用量的分布，但未系统性探索不同预算下的极限性能表现。
