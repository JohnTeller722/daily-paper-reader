## 摘要
长期记忆是LLM代理缺失的一层：跨会话时他们会遗忘，而常见的解决方式——将整个历史重放到提示中——昂贵、缓慢，并且随着干扰项的积累，准确性下降。大多数记忆系统在成本或延迟上胜出，但在准确性上仍不及全上下文基线，且基准分数在不一致、不可复现的框架上报告，因此同一系统在不同来源中得分差异巨大。我们提出了Engram，这是一个基于双时态数据模型的开源双过程记忆引擎。快速写入路径附无损事件，LLM不在关键路径上；异步路径提取原子（主体，谓词，客体）事实，构建双时态知识图谱，并在不每个事实调用LLM的情况下解决矛盾——无效化，从不删除，因此每个事实保留来源和替代链。混合读取路径融合稠密、词汇、图以及时效性/显著性信号，应用时间点（“截至”）过滤器，并组装一个紧凑的、带有来源标签的上下文。在完整的500个问题的LongMemEval_S上，由官方类别特定评判器评分，Engram的精简配置——从约9.6k token的检索片段回答，从未使用完整历史——得分为83.6%，而全上下文为73.2%（+10.4分，McNemar p < 10^-6），token数量减少约8倍（9.6k对79k），错误率为0/500。这一增益需要混合读取路径：仅事实会丢失召回，而事实加上检索的片段能恢复细节。我们还贡献了一个中立、仓库内评估框架，内置官方评判器，每个表格中都有全上下文基线，发布原始的每问题日志，并记录了测量完整性陷阱（截断、自建评判器、全历史泄露）——这些陷阱会无声地扭曲记忆基准。每个数字都附带可复现的命令。

## Abstract
Long-term memory is the missing layer for LLM agents: across sessions they forget, and the common workaround -- replaying the whole history into the prompt -- is expensive, slow, and, as distractors accumulate, less accurate. Most memory systems win on cost or latency but still lose to the full-context baseline on accuracy, and benchmark numbers are reported on inconsistent, non-reproducible harnesses, so one system appears at wildly different scores across sources. We present Engram, an open-source, dual-process memory engine on a bi-temporal data model. A fast write path appends lossless episodes with no LLM on the critical path; an asynchronous path extracts atomic (subject, predicate, object) facts, builds a bi-temporal knowledge graph, and resolves contradictions without an LLM call per fact -- invalidating, never deleting, so every fact keeps provenance and a supersession chain. A hybrid read path fuses dense, lexical, graph, and recency/salience signals, applies a point-in-time ("as-of") filter, and assembles a compact, provenance-tagged context. On the full 500-question LongMemEval_S, graded by the official category-specific judge, Engram's lean configuration -- answering from a ~9.6k-token retrieved slice, never the full history -- scores 83.6% vs. 73.2% for full-context (+10.4 points, McNemar p < 10^-6) at ~8x fewer tokens (9.6k vs. 79k), with 0/500 errored. The gain needs a hybrid read path: facts alone lose recall, while facts plus retrieved chunks recover detail. We also contribute a neutral, in-repo evaluation harness with the official judge baked in and the full-context baseline in every table, publish the raw per-question logs, and document the measurement-integrity pitfalls (truncation, home-grown judges, full-history leaks) that silently distort memory benchmarks. Every number ships with a command to reproduce it.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：LLM 代理（Agent）在跨会话时是**无状态的**，无法记住之前的交互。常见的缓解方法是**将全部历史对话直接拼接到提示上下文**中，但这会带来三个问题：
  - 成本高：token 数随历史线性增长；
  - 延迟高：处理长上下文变慢；
  - 准确率下降：根据 "Lost in the Middle" 现象，相关证据被大量干扰项淹没，模型难以定位。
- **背景**：尽管多种长期记忆系统（如 MemGPT、Mem0、HippoRAG 等）被提出，但 **大多数系统仅在成本或延迟上胜出，在准确率上仍不及全上下文基线**。同时，该领域的基准评测存在**不一致、不可复现**的问题（同一系统在不同来源中得分差异巨大）。
- **核心意义**：本文证明**精确检索的精简上下文不仅可以更廉价，而且可以比完整历史更准确**，从而将长期记忆从成本优化转变为质量提升。

## 2. 论文提出的方法论

### 核心思想
- 采用**双过程架构（Dual-Process）**：快速写入路径（System-1）和异步合并路径（System-2）。
- 构建**双时态数据模型（Bi-temporal Data Model）**：同时保留有效时间（世界中何时为真）和事务时间（系统记录/撤销时间），支持“截至某个时间点”的查询。
- **非破坏性冲突解决**：冲突事实被**无效化（invalidated）而非删除**，保留来源链和替代链。

### 关键技术细节
- **写入路径（System-1）**：添加消息时，无损记录原始会话片段（Episode），进行身份解析，计算轻量嵌入，并将片段入队等待异步合并。**全程无需调用 LLM**，延迟低于 50ms。
- **合并路径（System-2）**：异步进行以下操作：
  1. 从片段中提取原子事实（subject, predicate, object，示例："user works_at Tencent"）
  2. 构建双时态知识图谱（节点为实体，边为关系，均带时间戳）
  3. 冲突检测与解决：逐步升阶——精确槽位匹配、嵌入相似性、子句包含；仅对真正模糊的情况调用 LLM 仲裁。旧事实被无效化，新事实标记 supersedes 指针。
  4. 显著性评分与衰减（未受强化的记忆逐渐淡出）
- **读取路径（System-1 风格，但实际通过检索）**：
  - 并行使用四路信号：
    - 稠密语义搜索（BGE small 嵌入）
    - 稀疏词汇搜索（BM25）
    - 知识图谱 n 跳从查询实体出发
    - 时效性/显著性信号（指数衰减）
  - 使用**倒数秩融合（RRF）** 融合排序，并可选交叉编码器重排（默认关闭）。
  - 应用**时间点过滤器（as-of filter）** 只保留查询时间点有效的事实。
  - 通过**弃权门（abstention gate）**：当证据缺失时拒绝回答。
  - 组装包含**精简事实 + 原始会话片段 + 会话摘要**的混合上下文。

## 6. 论文的主要结论与发现

1. **精简上下文超越全上下文**：engram_lean（~9.6k tokens）准确率 83.6%，full_context（~79k tokens）准确率 73.2%，**提升 10.4 个百分点**，同时 token 减少约 8 倍。
2. **双时态建模是关键**：在知识更新（87.5%）、时间推理（81.1%）类别中表现突出，这是由于支持“as-of”查询和权威替换。
3. **混合读取路径必不可少**：仅事实会丢失细节（例如需要原文数字或精确表述的问题），加上原始会话片段后恢复性能。
4. **结构化事实而非完整历史带来准确性提升**：engram_full（事实+完整历史）得分 83.4%，与 engram_lean 几乎相同（p=0.91），说明**完整历史没有添加正确性，只增加了 token**。
5. **可复现评估框架的构建是同等贡献**：将官方评判器内置，修复测量陷阱（截断、自制评判器、全历史泄漏等），发布原始日志，使得跨来源比较成为可能。
